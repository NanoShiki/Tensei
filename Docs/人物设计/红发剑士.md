# 红发剑士

状态：第一位预设角色的设计初稿，待定稿与实现。男性、红发、剑士，以及开朗、神经大条、单纯的经典 JRPG 主角气质为已确定要求。姓名、年龄、种族、背景、服装、台词与成长表现均为本稿提案；尚未生成角色图片或游戏资产。

## 角色概念

**一个总会先笑着答应帮忙、再发现事情比想象中麻烦的红发见习剑士。**

他向往地下城深处的未知，也认真相信冒险者能帮助别人。初见时显得热情、好相处、有点冒失；相处久了会发现，他答应过的事总会记在心里。

## 性格与行为

- **开朗**：主动打招呼，见到新装备或新地方会露出明显的兴奋；遭遇小挫折后恢复很快。
- **神经大条**：对暗示、讽刺和微妙气氛反应慢，别人客套一句“下次请你吃饭”，他会认真问哪天。
- **单纯直率**：喜欢谁、佩服谁就直接说，收到感谢会笑得很开心；说谎时很容易从脸上看出来。
- **热心而冒失**：常常先答应帮忙，再发现自己多背了两袋行李；容易低估准备工作的分量。
- **认真时可靠**：练剑和应对眼前危险时能集中注意力，看到同伴受伤会迅速收起笑容，先处理撤退与保护。

他的短板是判断经验和分寸：容易相信漂亮话，也容易把“我还能撑住”当成队伍还能深入的依据。后续成长让他学会先询问伙伴状况、准备补给和判断撤退时机。日常喜剧以误解暗示、过度热心和直白表达为主，保留基本生存常识与伙伴尊严。

生活小习惯建议：边听冒险故事边比划招式；被夸奖时抓后脑勺；习惯把干粮掰一半给同伴；记不住昂贵装备的全名，却记得是谁帮他修好了剑。

## 背景与关系提案

在城郊驿站长大，帮家里搬货、送东西，常听往来冒险者讲述地下城。曾跟着一位退下来的护卫练基础剑术，用积蓄买下一把旧剑，来到城市开始正式冒险。

最初的目标很具体：赚够维护装备和住宿的钱，再带一件自己找到的纪念品回家。随着探索深入，他逐渐有了“能护送新人、让伙伴安心把后背交给自己”的愿望。出生地、家庭成员及师傅身份等世界观专名待整体设定确定。

他会主动和谨慎的同伴商量下一步，经常需要对方提醒费用与风险；面对新人，愿意分享第一次进地下城时的糗事；面对商人，容易被夸奖打动，经历吃亏后开始认真记价格。这些关系用于塑造生活感，具体 NPC 待设计。

## 外貌与初始服装提案

- 头发为偏暖的铜红色短发，头顶蓬松，刘海有几撮不太服帖的翘发，露出眉眼，背面轮廓清楚。
- 琥珀棕眼睛，眉毛稍粗，面部线条清爽，常带张口笑；肤色略带户外活动的健康感。
- 米白色粗布衬衣，卷到前臂的袖口，深棕短皮背心，灰蓝长裤和耐磨短靴。
- 低饱和青绿色短领巾作为红发之外的第二识别点，衣服带少量修补痕迹；扣件朴素，整体表现刚入行的见习剑士。
- 初始武器建议为保养过的旧单手直剑，普通十字护手、缠布握柄与皮制剑鞘。职业不锁定该剑的长期使用。

色彩以红发、米白布料、棕皮革和少量青绿形成层次。初始立绘突出学徒感、精神和生活痕迹；局内缩小后优先保留发型、头身比例与领巾色块。

## 战斗与动作表现建议

第一阶段可优先使用该角色验证创建、移动与攻击流程，实际纳入范围随阶段计划确认。基础剑术强调清楚的斩击与收招，起步轻快、挥剑投入，攻击后有短促的呼气。具体技能、数值和连段规则待战斗系统设计。

性格通过待机、表情和胜利动作传达，例如活动肩膀、露出期待的笑容、获胜后回头确认队友。玩家操作遵循统一输入规则，自动冲锋或强制冒险行为不纳入本稿。

局内资产按现有部件与武器动作体系制作：前后头发、脸、领巾、躯干、袖臂、腿靴及武器挂点分别考虑。领巾保持短小，先降低多方向遮挡与摆动适配量。动作镜像、持剑手和剑鞘位置按统一规格验证。

## 成长插画提案

| 阶段 | 插画表现 |
| --- | --- |
| 初始：见习剑士 | 地下城入口附近，整理肩上行囊，一只手握着剑鞘，朝即将同行的人露出坦率笑容；衣着朴素，构图预留界面空间 |
| 成长阶段 | 装备经过修补与添置，站姿更稳，表情依旧明朗；具体解锁条件待设计 |
| 狂战士派生示例 | 更有力量感的姿态和重型装备，战斗神情专注，保留红发、眼睛与青绿布料等身份特征；具体武器随职业规则决定 |

狂战士为可能的派生与插画方向，玩家的职业路线仍遵循职业系统。其他派生可分别表现守护或魔剑方向，具体覆盖待确认。各阶段保持同一角色身份，插画中的装备与实际装备按 [角色插画与成长解锁](../角色系统/角色插画与成长解锁.md)处理。

## 台词与声音提案

- 初次见面：“我叫洛恩！你也要下地下城？那一起走吧！”
- 被夸奖：“真的？嘿嘿，我练了挺久的。”
- 接下委托：“行，交给我！……等一下，两袋都要搬啊？”
- 发现新路：“前面还有路！先记下来，等大家补给好了再去看看。”
- 同伴受伤：“靠我这边！我们先退回去。”
- 成长后：“我也想继续往下。不过今天先带大家回家。”

声音建议明亮、自然、有朝气，认真时语速变稳；配音语言、演员或生成方式待音频方案确定。
