# 项目文档导航与文档树

本文是项目文档树的唯一维护入口，覆盖 `Docs/` 下全部 Markdown 文档。树按阅读职责与主题组织，链接对应实际文件位置；缩进表示阅读层级与主题归属，跨模块依赖由各文档中的引用说明。开发优先级和完成状态统一查看开发计划。

## 阅读与维护约定

先了解全局方向和当前计划，再阅读任务所属模块及必要依赖；实现说明用于核对已有行为，素材记录用于核对制作与验收证据。文档中的“已确定”表示设计方向明确，实际完成状态以开发计划和对应验收证据为准。

新增、移动、重命名、合并或删除文档，以及调整主题归属时，在同一次变更中更新本树和受影响的链接。每个条目保留简短职责说明，具体规则在对应文档维护。完整要求见 [项目文档规范](项目规范/项目文档规范.md)。
