# 俯视角色动作资产规范

状态：本轮制作规格。先固定规格，再生成与验收。当前仅制作洛恩空手行走、跑步；平视动作图已删除。

## 参考与采用范围

- [SLYNYRD：俯视角色动画](https://www.slynyrd.com/blog/2025/3/24/pixelblog-55-top-down-character-animation)：参考三分之四俯视投影、统一画布位置与多方向动作比对。观察头顶、肩部和脚面，检查肢体比例与循环相位。
- [OpenGameArt：八方向行走与待机](https://opengameart.org/content/8d-runwalk-idle-sprite-sheet)：参考方向组织与固定单格的思路。

上述资料用于学习视角与动画组织。项目继续使用原创洛恩设计和非像素二次元画风。下面尺寸为项目自身制定。

## 固定规格 V2

| 项目 | 本轮规定 |
| --- | --- |
| 投影 | 固定三分之四俯视，镜头向下约 45 度；正交感，无地平线 |
| 视觉检查 | 正向可见明显头顶，肩部上表面、躯干与腿部有俯视压缩；侧向也保持同一俯角 |
| 文件 | 行走、跑步各一张透明 RGBA PNG；只保留当前透明版本 |
| 画布 | 1024×1024 像素 |
| 网格 | 4 行×4 列，无外边距，无格间距 |
| 单格 | 256×256 像素 |
| 行顺序 | 第 0 行南、第 1 行东、第 2 行北、第 3 行西，以屏幕方向命名 |
| 列顺序 | 第 0 至 3 列对应时间顺序；左右腿交替完成一个循环 |
| 地面锚点 | 单格内 (128,224)，表示身体在地面的投影中心；腾空时保持该虚拟锚点 |
| 安全边距 | 每格四边至少 16 像素透明区，主体不越格 |
| 比例 | 约四头身的局内简化造型；同一角色各动作保持比例和尺度 |
| 手部与武器 | 行走、跑步空手。攻击随系统实现制作，具体武器独立挂接 |
| 预览速度 | 行走 6 FPS、跑步 8 FPS，均可调；四帧为首轮验证范围 |

切片区域为 Rect2(列×256, 行×256, 256, 256)。切片尺寸完全由规格确定。生成图的大小、排列或锚点不符合时必须返工，禁止对任意尺寸直接四等分并宣称可用。

## 生成与验收顺序

先确认已认可的人物身份参考；提示词明确俯视投影、尺寸、网格、锚点、空手与透明背景。逐项检查实际输出，只有尺寸、RGBA 和透明边界通过后才能更新素材清单。

检查每格主体完整、方向正确、脚底锚点、身份比例、双腿交替、接触与腾空相位、首尾循环。透明区应为 Alpha 0，主体内部保持不透明，半透明仅用于边缘抗锯齿。深浅底检查白边、杂色、光晕和残留背景。技术尺寸合格与动画可用性分别记录。

生成失败的候选不收入角色当前素材包。原画与设计稿保留其用途所需场景或底色；独立动作图只交付透明版本。四向待机待本轮俯视方向通过后补齐。

用户已授权脚本规范化：允许逐帧定位、清理 Alpha、统一缩放并重新打包。最终文件严格符合上述固定网格。
