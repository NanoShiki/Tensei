# 全局肉鸽机制

状态：策划初稿，待实现。神明赐福影响战局与重复游玩为已确定方向；长期关系、临时赐福的划分，以及具体效果、规则和名称为建议。

## 目标与世界观表达

肉鸽机制贯穿地下城冒险，影响战斗能力、资源收益、职业条件、任务、交易和探索机会。系统需要读取其他冒险系统提供的信息，并通过明确的规则对其施加影响，支持后续持续扩展。

引入《地错》式的神明、眷属与眷族关系，将肉鸽选择表现为神明赐福、神谕、契约和试炼。参考 Hades 将神明身份与赐福风格关联的方式，让每次选择同时表达世界观、角色关系与玩法变化。

玩家接触神明力量的机会可来自神龛、遗迹、眷族使者、任务奖励或特殊遭遇。具体载体为候选。参考资料见 [《地错》官方用语](https://danmachi.com/danmachi/special/index.html)与 [Hades 官方介绍](https://www.supergiantgames.com/blog/hades-faq/)。本项目的神明名单、关系和规则需要独立设计。

## 神明与眷属关系建议

| 概念 | 项目中的建议职责 |
| --- | --- |
| 神明 | 提供主题、价值取向、赐福和试炼来源 |
| 眷属 | 表达角色与神明的归属或契约关系 |
| 眷族 | 承载组织、人际关系、委托和成长机会 |
| 赐福 | 形成可组合的战斗或经营效果 |
| 神谕与试炼 | 将职业条件、探索目标和风险收益纳入冒险 |

建议将长期眷族关系或试炼进度纳入角色存档，将本次远征的神谕、赐福与契约纳入远征状态。这样角色的永久升级、锻造与转职持续积累，随机选择改变每趟战术。长期眷族关系与一次赐福的有效期分别记录。正式加入眷族、接受其他神明帮助、转换归属和获得多神组合的规则待确认。

## 跨系统作用范围

以下均为效果示例，具体强度与神明归属待设计：

| 领域 | 可读取的信息 | 效果示例 | 生效规则负责方 |
| --- | --- | --- | --- |
| 战斗 | 职业、武器类型、当前状态 | 战斗赐福改写已有技能的效果、行动次数或合法目标 | [回合制战斗](../战斗系统/回合制战斗.md) |
| 掉落 | 怪物类型、战利品类别、已有祝福 | 狩猎赐福提高指定材料的掉落机会 | 掉落规则 |
| 资源经营 | 背包、材料需求、供应情况 | 丰饶赐福提高材料数量或补给收益 | 物品与资源规则 |
| 交易打造 | 当前商店、配方、交易条件 | 商旅契约改善收购价，锻造恩惠减少材料消耗 | 交易与打造规则 |
| 职业 | 基础职业、已获得的派生职业、各阶段进度、等级、持有道具 | 战神试炼提供狂战士派生条件，契约事件提供召唤师后续分支条件 | 职业规则 |
| 任务探索 | 当前楼层、已完成事件、任务阶段 | 神谕开启特殊委托或遭遇 | 任务与探索规则 |

肉鸽系统承担跨模块选择与协调职责。各模块保留自身状态、消耗、奖励和合法性判定，肉鸽效果通过其公开的规则入口参与计算。实现形式留待技术细化。

## 一次选择的流程

1. 根据位置、角色、队伍和已发生事件确定可出现的神明机会。
2. 按前置、互斥、已持有效果和重复规则生成候选。
3. 展示神明来源、收益、代价、作用对象和有效期限。
4. 玩家确认后，按 [玩家主机联机](../联机/玩家主机联机.md)的权威规则确认结果。
5. 相关系统应用效果或推进事件，记录来源和生效状态。
6. 条件结束后移除对应临时影响，保留已合法产生的物品与已达成进度。

## 扩展与组合约定

每个选项需要能够表达来源、出现条件、触发事件、作用对象、影响内容、代价、叠加方式、互斥关系和终止条件。效果可以组合数值变化、规则变化和事件机会，后续新系统应能加入这一体系。

“全局关联”描述可影响的系统范围。每条效果还需明确属于个人、队伍、某区域或整个共享世界。效果顺序、概率上限、相同效果叠加和触发循环的处理方式必须在对应规则实现前确定。

职业解锁条件应由职业系统确认；赐福可提供事件、资格标记或所需资源。一次随机机会与永久解锁结果分别记录，避免临时效果到期时误删正式成长。

肉鸽机会需要支持 [职业与派生成长](../角色成长/职业与派生成长.md)中的多层路线。候选事件可根据已获得的派生职业和目标分支条件出现，例如为召唤师提供亡灵试炼、植物契约或动物契约机会；这些事件及条件仍属设计示例。

## 有效期与连续探索

肉鸽机制运行在长期角色培养与连续地下城探索中。随机选择提供战斗和资源变化，永久成长由 [角色存档](../角色系统/角色存档与长期成长.md)记录；每次进入地下城沿用已培养角色。

终局可对首领附加随机效果，并配合随机首领遭遇提高重复挑战的变化。首领池和基础强度由 [深层终局挑战](../世界与探索/深层终局挑战.md)维护，肉鸽系统协调效果的候选条件、作用对象、叠加、互斥和期限。首领强化、环境变化与玩家赐福分别表达并同步，具体效果和数值待设计。

为创意工坊预留效果注册与内容依赖接口，具体可开放范围见 [发行与创意工坊](../平台与扩展/发行与创意工坊.md)。

候选有效期包括持续一段时间、指定次数、某片区域、完成契约前或长期保留。每条效果必须有明确说明。

返回城市后，物品按背包规则保留。临时赐福是否保留、暂停或结束需要逐类确定。本次提议以从第一层出发至返回城市作为一趟远征。回城后哪些临时效果结束、延续或转化为长期关系仍待确认；每条效果需明示期限。

需要同时设计反复往返、重新加入房间和读取存档时的机会领取规则，避免重复刷取同一事件奖励。

### 与返程刷新的结合

神明赐福可读取地图节点的刷新进度、返程威胁和角色当前补给，提供侦察、更快通过、降低一次避战代价或刷新遭遇的战斗优势。所有效果须说明作用的节点、次数、期限和结算顺序，不能让玩家凭未知效果承担隐性损失。额外行动属于高影响战斗效果，建议稀有、限次数并防止连续触发。

这部分为设计建议；当前地图 Demo 没有赐福、返程或刷新。完整循环见 [整体玩法设计](../游戏整体/整体玩法设计.md)。

## 连贯示例

建议示例：剑士在城市接到眷族委托，进入地下城后遇到战神试炼。玩家接受试炼并讨伐指定敌人，获得职业条件进度和怪物材料，在安全楼层完成一次受限交接，再带着材料回城打造武器。职业系统核对完整条件后开放狂战士路线，试炼附带的临时赐福按自身期限处理。

## 表现与待确认事项

神明使用统一的肖像、徽记、色彩和音画反馈表达身份，选择界面突出效果、代价及期限。素材制作遵循 [美术风格与素材制作](../美术/美术风格与素材制作.md)。

待确认：神明与眷族名单、加入机制、赐福数量、随机权重、刷新与保底、多神组合、队伍选择方式、临时效果的探索周期，以及长期关系成长的具体形式。
