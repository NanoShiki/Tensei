# 美术风格与素材制作

状态：策划初稿，待实现。本轮确立风格与制作方向，具体素材按后续功能需求生成。

## 已确定方向

整体美术参考日式西幻，以《地错》与《刀剑神域》为重点、《无职转生》为补充。《刀剑神域》的具体视觉参考范围待风格样张阶段细化。角色、怪物、装备、建筑、界面和特效应形成一致的冒险世界。项目美术素材主要由 AI 代理调用生图模型获得。

## 视觉建议

- 角色通过轮廓、服装、持械方式和施法表现传达职业身份，换装与派生需要保留可辨识的角色特征。
- 城市呈现生活、工坊、商贸和冒险准备氛围；地下城通过地貌、怪物和照明表达深度与危险；安全楼层使用清晰的补给设施与聚集区标识。
- 武器与怪物素材保留可追溯的外形、纹理或颜色关联，让玩家能够理解打造来源。
- 攻击预警、敌我识别、交互目标和掉落物在战斗画面中优先保持可读性。稀有度通过图形、文字与颜色共同表达。

## 生图制作流程

1. 阅读素材所属模块的文档，整理用途、主体、风格、视角、构图、尺寸、背景透明需求及交付形式。
2. 首批生成风格样张和角色或场景参考图，选定视觉基准后持续复用参考，保持系列一致性。
3. 按任务调用生图模型，检查轮廓、装备结构、比例、光照、边缘及批次一致性，必要时继续编辑生成结果。
4. 对采用的素材整理用途、提示词、参考图、规格与项目内路径，记录在对应模块文档或素材目录的说明中。
5. 导入 Godot 后检查实际显示效果；有动画、方向帧或切片需求时，逐项验证衔接和可用性。

生图结果需要按游戏用途加工和验证。角色动画、碰撞、模型及绑定的制作方式随最终表现形式细化。

## 待确认

- 2D、3D 或混合表现，镜头角度与角色屏幕尺寸。
- 线条、上色、明暗、材质和特效强度的具体基准。
- 各类素材的分辨率、方向数量、动画规格和目录规则。
- 首批风格验证对象与采用标准。
