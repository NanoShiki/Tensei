## 已确定方向

武器为战斗提供一组攻击技能，决定角色的基础攻击手段，更换武器会改变可用技能，见 [回合制战斗](../战斗系统/回合制战斗.md)。武器获取以怪物掉落素材、玩家按需求打造为主。宝箱可直接奖励武器或素材，首领和特殊怪物也可能掉落特殊素材或武器。不同来源共同支持玩家规划目标与获得意外收获。建议让图鉴关联怪物、材料和配方，使刷取有明确目标；随机属性或低概率掉落提供惊喜，具体保底规则待平衡。

## 获取与使用链路

1. 玩家根据职业、偏好和现有装备确定目标武器。
2. 通过普通怪物、首领、特殊怪物、宝箱或任务取得材料与武器。
3. 所得进入背包并延续到城市；玩家决定保留、出售、交付或用于打造。
4. 在具备打造能力的地点查看需求并制作，再装备使用。

打造地点建议以城市工坊为主，由锻造眷族经营；预计可以有一两个风格不同的锻造眷族，具体数量待内容规划。地下城是否提供有限打造服务待确认。

## 锻造眷族与工坊成长

玩家可以在锻造眷族的工坊购买基础打造与修理服务，当前所属眷族可以是远征、经商或另一家锻造眷族。建议完成制作、修理或工艺委托后，为服务方眷族积累贡献；按实际消耗的材料、成品价值和委托完成情况结算，重复制作廉价物品需防止无成本刷级。贡献归属、组织等级与跨角色保留由 [眷族体系与成长](../角色系统/眷族体系与成长.md)维护。

角色加入锻造眷族后，可获得该组织的成员任务与工艺优势。建议初期选择容易理解的收益：更多配方或材料替代方案、更少的锻造废料、更可靠的品质选择、较低的修理成本；具体组合与数值待平衡。会员收益在界面显示来源和节省量，不通过隐藏概率让玩家猜测。基础武器仍允许其他眷族成员购买，避免某条主游戏成长路线因归属被锁死。

两家锻造眷族如果并存，应有不同的工艺身份：例如一家擅长稳定量产，另一家擅长稀有材料与改造。制作出可用装备同时推进角色配装目标和工坊组织成长，让城市活动本身形成可重复的养成循环。锻造眷族的随行队友可以偏工匠、修理或道具支援，战斗力不必等同于远征型眷族；是否允许每位工匠出战待定。

## 武器设计建议

| 维度 | 设计作用 |
| --- | --- |
| 武器类型 | 决定基础攻击方式、距离、节奏和持械动作 |
| 素材来源 | 提供属性或特性倾向，关联怪物视觉特征 |
| 特殊能力 | 改变攻击、技能或职业配合方式 |
| 打造需求 | 说明材料、货币、配方和可能的解锁条件 |
| 获取来源 | 帮助玩家安排讨伐、探索或委托目标 |

初期类型可研究剑、重型近战武器、法杖、弓和匕首；最终范围随职业与动作设计确定。直接掉落武器与打造武器的品质关系待细化。

## 示例

建议示例：玩家从图鉴与眷族委托得知导电素材来自雷属性怪物，计划讨伐后在城市打造带雷电特性的剑。职业派生也可将持有该武器作为条件之一。怪物、材料、武器名称及属性数值均待设计。

## 信息与联动

武器需要关联动画系统：普通武器复用对应类型的动作集，特殊武器可以配置专属动作。每件武器关联适用的动作配置，武器自身的运动与角色部件统一协调播放。动作解析、兼容规则、专属覆盖与回退方案统一维护在 [角色创建与外观动画](../角色系统/角色创建与外观动画.md)。这些设计待实现，具体动作类型与覆盖范围待验证。

配方应说明需求与当前持有数量。武器展示需要传达攻击特点、使用条件与特殊效果。制作前应清楚显示消耗，制作成功后更新背包与装备选择。

常规地下城掉落由怪物、楼层、图鉴与任务规则决定，不依赖终局临时赐福。终局若产出可带回的素材，须按独立奖励表和战利品归属结算，见 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)。物品持有与流转统一遵循 [背包与物品流转](背包与物品流转.md)。
