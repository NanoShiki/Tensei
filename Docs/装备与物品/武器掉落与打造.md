# 武器掉落与打造

状态：策划初稿，待实现。

## 已确定方向

武器为战斗提供一组攻击技能，决定角色的基础攻击手段，更换武器会改变可用技能，见 [回合制战斗](../战斗系统/回合制战斗.md)。武器获取以怪物掉落素材、玩家按需求打造为主。宝箱可直接奖励武器或素材，首领和特殊怪物也可能掉落特殊素材或武器。不同来源共同支持玩家规划目标与获得意外收获。

## 获取与使用链路

1. 玩家根据职业、偏好和现有装备确定目标武器。
2. 通过普通怪物、首领、特殊怪物、宝箱或任务取得材料与武器。
3. 所得进入背包并延续到城市；玩家决定保留、出售、交付或用于打造。
4. 在具备打造能力的地点查看需求并制作，再装备使用。

打造地点建议以城市工坊为主，地下城是否提供有限打造服务待确认。

## 武器设计建议

| 维度 | 设计作用 |
| --- | --- |
| 武器类型 | 决定基础攻击方式、距离、节奏和持械动作 |
| 素材来源 | 提供属性或特性倾向，关联怪物视觉特征 |
| 特殊能力 | 改变攻击、技能或职业配合方式 |
| 打造需求 | 说明材料、货币、配方和可能的解锁条件 |
| 获取来源 | 帮助玩家安排讨伐、探索或委托目标 |

初期类型可研究剑、重型近战武器、法杖、弓和匕首；最终范围随职业与动作设计确定。直接掉落武器与打造武器的品质关系待细化。

## 示例

建议示例：玩家讨伐特殊雷属性怪物获得导电素材，在城市打造带雷电特性的剑。肉鸽选择可提高目标素材的获取机会，职业派生也可将持有该武器作为条件之一。怪物、材料、武器名称及属性数值均待设计。

## 信息与联动

武器需要关联动画系统：普通武器复用对应类型的动作集，特殊武器可以配置专属动作。每件武器关联适用的动作配置，武器自身的运动与角色部件统一协调播放。动作解析、兼容规则、专属覆盖与回退方案统一维护在 [角色创建与外观动画](../角色系统/角色创建与外观动画.md)。这些设计待实现，具体动作类型与覆盖范围待验证。

配方应说明需求与当前持有数量。武器展示需要传达攻击特点、使用条件与特殊效果。制作前应清楚显示消耗，制作成功后更新背包与装备选择。

掉落受到 [全局肉鸽机制](../肉鸽系统/全局肉鸽机制.md)影响时，仍须遵守战利品归属与领取规则。物品持有与流转统一遵循 [背包与物品流转](背包与物品流转.md)。

## 待确认

- 配方获取、品质、随机属性、强化和拆解范围。
- 装备数量、切换成本、耐久与绑定规则。
- 普通掉落、特殊掉落和保底机制的关系。
- 联机个人掉落、公共掉落、分配与玩家交易规则。
