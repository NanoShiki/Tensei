# 背包与物品流转

状态：金币、铁片、两类药水与当前武器的最小随身资源已实现，跨城市和远征延续并随角色快照保存。个人武器列表与城市装备选择已接入，格位背包、仓库、出售、丢弃和完整物品系统仍待实现。

当前战斗胜利结算一次获得 3 金币和 1 铁片，重复结算拒绝；回城不再次领奖。城市购买与打造、集市供货与会员礼包直接更新持有资源；供货消耗的铁片与锻造及材料委托共用库存，个人订单状态随快照恢复，服务方共享贡献独立去重。费用及验收统一见 [当前城市 Demo](../世界与探索/城市与地下城探索.md)。地图与城市顶部提供“背包 · B”入口，可点击或按 B 打开；显示当前武器、剑技加成、金币、铁片、两类药水数量与用途。B／Esc／关闭按钮退出，内容区支持滚动。当前为资源列表，格位与容量尚未定案。

探索或返程地图、城市中可使用治疗药水：消耗 1 瓶，最多恢复 12 生命；满血、无药、战斗待结算、死亡和回城摘要均不能使用。成功用药不计移动步数、不推进怪物刷新；战斗中继续通过底部道具选择目标并消耗行动。灼烧药水可在战斗使用，或在下一步遭遇预览消耗一瓶掩护绕行，详见 [探索](../世界与探索/地下城推进与怪物之宴.md)。用药后界面与存档快照使用同一份角色状态，仍需手动保存。

验收：F5 创建角色／继续记录 → 地图或城市点击背包或按 B；受伤后使用治疗药水，应恢复至多 12 生命且库存减 1，地图步数及刷新计时不变。满血或无药时按钮禁用；B／Esc 关闭。保存并退出后继续，应保持用药后的生命和库存。通过 GM 打开日志目录，inventory.field_potion 含操作前后状态；日志检查工具核对消耗和计时。`Tests/test_inventory.gd` 覆盖实际按钮、输入开关、拒绝无副作用、返程用药、磁盘恢复与日志检查所需事件。

背包显示持有的木剑、铁剑与淬火铁剑；城市“工坊／装备”可选择，探索中保持出发装备。制作保留旧武器，当前装备和持有列表随个人记录保存，转会保留；配方与效果见 [武器掉落与打造](武器掉落与打造.md)。

## 已确定方向

背包承载玩家持有的武器、材料、道具与任务物品。玩家进入地下城、在安全楼层活动和主动返回城市时，尚未消耗、出售、丢弃或交付的物品持续保留。

物品在地下城获得后即可成为持有资源。跨区域流转支持城市打造、交易、任务交接和再次出发时使用。

## 流转规则建议

| 行为 | 物品变化 |
| --- | --- |
| 拾取或领取奖励 | 按容量与归属规则加入背包 |
| 装备或快捷选择 | 更新使用位置或引用，保持同一件物品身份 |
| 使用消耗品 | 成功生效后扣除对应数量 |
| 打造、交易或任务交付 | 校验条件后统一处理消耗与产出 |
| 主动往返城市与地下城 | 延续当前携带物品 |
| 存入家园仓库 | 转移持有位置；仓库范围待确认 |

任务交付、制作与出售应清楚展示将消耗的物品。涉及特殊武器或职业条件道具时，应能帮助玩家识别其用途。

## 快捷交互

按 B 打开背包。Tab 快选与数字快捷栏从可用物品或装备中选择，背包负责持有数量与可用状态。背包中的消耗、出售与丢弃应同步反映到快捷栏，避免留下可操作的失效条目。

具体输入约定见 [战斗操作与界面](../战斗与操作/战斗操作与界面.md)。图标应帮助辨识类型、数量、品质与特殊用途。

## 状态边界

主动返回的物品保留已经确定。死亡、团灭、断线及主机退出后的物品保留需要单独设计。临时召唤物与具有明确到期条件的特殊道具，应在获取时说明有效范围。

已确定使用同一角色存档进行单人和联机，携带已培养角色的装备与物品进入兼容房间。合法取得的物品按归属规则保存到角色存档，具体携带限制、入房校验与保存协议待细化，见 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)和 [玩家主机联机](../联机/玩家主机联机.md)。
