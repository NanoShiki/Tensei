# 眷族与队友成长

状态：设计提案，尚未实现。以下“已确定方向”整理用户本次提出的目标；归属、解锁、跨角色共享与转会细则为待验证方案。“眷族”为本项目统一术语；与神明的关系、组织名称和角色造型需使用项目原创内容。

## 定位与玩家体验

眷族是与角色等级、职业和装备并行的长期团队养成系统。玩家先完成特定任务获得加入资格，加入后可接眷族任务、招募该眷族的队友共同远征。队友随远征成长，眷族本身也会因成员贡献而变强，逐步开放新的队友、设施、任务与能力。玩家可以转入其他眷族，也可以创建另一名角色，加入自己已经培养起来的旧眷族。

这条系统服务常规冒险的长期目标。部分眷族成长成果可以在后续终局肉鸽中解锁可选择的赐福；终局玩法的临时效果与眷族的长期进度分别保存，见 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)。

## 加入资格与任务分层

每个眷族拥有自己的入门任务、进阶任务、队友和发展方向。加入资格可以来自一项或多项条件；条件应在界面中明示，允许玩家有目标地准备。

| 层级 | 内容示例 | 目的 |
| --- | --- | --- |
| 入门 | 讨伐数只哥布林、交付常见素材、帮神明跑腿或护送物资 | 让新角色及早加入一个团队，认识其价值观 |
| 成员 | 指定楼层调查、协助眷族队友、按时带回材料 | 推动成员和据点成长，展示团队协作 |
| 高阶 | 击败指定首领、达到等级或资金门槛、完成职业试炼 | 为强势眷族或高级职位提供明确目标 |
| 专属长期目标 | 处理眷族危机、建设设施、与另一组织竞争 | 解锁独特队友、故事与终局赐福候选 |

“普通”与“强大”描述门槛及当前影响力，不预设后者的道德高低。入门友好的眷族也能通过长期培养发展壮大。任务可在常规地下城中完成；刷新怪物可用于普通讨伐计数，首领、特殊材料和唯一事件的奖励仍按各自领取规则处理。任务进度、奖励和联机贡献都应可查询、可复核。

## 成长的四个对象

| 对象 | 建议保存内容 | 归属与作用 |
| --- | --- | --- |
| 玩家角色 | 等级、职业、技能、个人装备、个人任务与当前眷族 ID | 每个角色自己的存档；同一角色同一时刻归属一个眷族 |
| 玩家档案中的眷族 | 每个眷族的声望、建设等级、设施、任务完成记录、解锁项 | 同一玩家的多个角色共享；转会或暂时无人加入时仍保留 |
| 眷族队友 | 队友 ID、等级与能力、装备归属、关系及可招募状态 | 属于该玩家档案中的眷族队伍；随远征成长且不会因主角转会清零 |
| 当前远征 | 参与者、生命与道具、已走路线、怪物刷新及战利品 | 一趟下潜和返程的临时状态；完成结算后按归属回写 |

**建议的数据关系**：一个玩家档案可有多个角色存档和多个独立的眷族进度。每个角色存档只有一个当前眷族归属；一个眷族进度可关联多名该玩家的角色和该眷族的队友。角色存档不复制眷族成长数值，只持有稳定 ID 与个人贡献记录。这样新角色加入旧眷族时读到同一份成熟的设施和队友数据。

现有“一档一角色”保留为单个角色存档的粒度；玩家拥有多个角色档位时，档位上方增加共享档案。账号、云存档、离线档案以及联机时该共享档案的所有权规则尚需技术设计，见 [角色存档与长期成长](角色存档与长期成长.md)。

## 招募与队友成长

队友由各眷族提供，可以是初始成员，也可以通过任务或设施解锁。招募前展示职业定位、当前能力、个人故事、远征成本和是否可以加入本次队伍；队伍上限、雇佣费与离队规则待确认。加入同一眷族提供招募资格，个别队友仍可有关系或任务要求。

队友参加地下城讨伐后获得经验、技能熟练度、个人关系或转职机会。建议把奖励与实际参与挂钩，并设置合理的后备队伍成长途径，避免玩家只能重复刷低层练每一名队友。队友的成长是长期记录，死亡与受伤规则单独设计；装备应标识个人所有、眷族库房所有或借用。

眷族整体成长建议来自任务贡献、带回的材料、成员突破和设施建设。提高等级可扩充招募名额、开放新的高阶任务、补给或工坊服务，并解锁与其神明主题对应的终局赐福候选。每次升级要让玩家看见本部和队伍产生实际变化；数值、上限、建造材料与增益范围待平衡。

高等级队友能帮助新角色认识地下城，也可能让低层战斗过于轻松。建议允许这种“老眷族带新人”的爽点，同时通过招募名额、队友出场成本和高级奖励的层级要求控制资源产出；具体限制不能抹去既有培养成果。跨角色继承的是眷族与其成员，角色自身等级、装备和个人职业仍按角色存档处理。

## 转入其他眷族

已确定方向：角色可以离开当前眷族，尝试加入另一眷族；原眷族的积累保留，未来的新角色可以加入。以下为建议的交接规则：

1. 在城市确认转会，展示资格、费用和将失去的当前访问权限。正在进行的远征先结算或结束，避免队伍归属在战斗中变化。
2. 旧眷族的等级、设施、已培养队友、已完成任务与已解锁内容留在玩家共享档案；旧眷族队友退出该角色的当前远征编成，回到自己的眷族名册。
3. 角色的个人等级、已学职业技能、个人装备与完成过的个人试炼继续属于角色。旧眷族授予的临时权限、借用装备和进行中的专属任务按事先公布的规则归还或暂停；不会抹掉完成记录。
4. 新眷族按自身入门条件接纳该角色；它的建设与队友从该眷族在玩家档案中的已有进度读取。若首次加入，则从该眷族的初始状态成长。
5. 角色或新建角色将来再加入旧眷族时，可使用保留的设施和已培养队友。个人专属资格仍单独检查。

角色是否可以随时转会、转会冷却或费用、跨眷族借队友、神明授予的永久能力能否在转会后继续使用，都尚未确定。推荐先不做频繁切换收益的设计：任务奖励按唯一 ID 结算，借用物品与眷族特权按当前归属验证，已永久学习的普通职业技能不因转会删除。

## 眷族与终局赐福

眷族长期成长可解锁对应神明的终局赐福候选、起始契约、队伍支援或特殊试炼入口。解锁资格保存在玩家共享档案中；一趟终局肉鸽里实际抽到或选到的效果保存在该次挑战状态中。常规冒险以等级、装备、职业、眷族任务和队友成长为主要养成来源，终局挑战接收已经养成的角色和装备。

建议旧眷族已解锁的通用赐福候选在转会后继续进入终局可选池，使建设旧眷族始终有价值；当前所属眷族可提供主题权重或专属契约。具体哪些能力跟随当前归属、哪些作为共享解锁，需要在终局原型前定稿。这种候选解锁不保证每次终局挑战都能获得该赐福。

## 一段跨角色示例

角色甲加入旅神眷族，通过护送和返程任务培养两名队友并建设据点。之后甲转入炉神眷族，个人剑术与武器保留，旅神的设施和队友留在共享档案。角色乙新建后加入旅神眷族，能看到成熟的据点并招募两名已成长的队友；乙自己的等级、职业和装备从个人起点开始。旅神长期进度解锁的返程赐福进入终局候选池，角色甲与乙使用哪些候选由最终解锁规则决定。人物、神明与任务名称均为示例。

## 实现顺序与待确认

建议先验证一个入门眷族：加入任务、两名队友、一种团队贡献、一次队友成长和持久化。随后实现第二眷族、转会与新角色加入旧眷族，验证共享档案和所有权。终局赐福只先登记解锁，不急于制作肉鸽挑战。

待确认：眷族的具体名单与神明设定、一个玩家可创建多少角色、共享档案边界、进入高阶眷族的资格、队友成长和伤亡、眷族库房与借出装备、转会成本、跨眷族队友和技能的访问限制、联机中的贡献与共享数据所有权、终局赐福是否跨眷族可选。
