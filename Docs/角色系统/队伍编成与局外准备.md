# 队伍编成与局外准备

状态：策划初稿，待实现。队伍由长期培养的角色及其当前眷族可招募的队友组成，装备、技能与补给在出发前配置；队伍规模、招募成本与背包格位数值需要原型验证。

## 局外准备的位置

局外准备是每次探索的起点，决定玩家带着什么进入地下城。由于局内资源不自动补满，出发时的选择直接决定能走多深，见 [行动与补给](../战斗系统/行动与补给.md)。

准备包含三件事：编成队伍、配置技能、携带补给。三者共用同一份背包与资金，互相挤占。

## 队伍编成

玩家的本体角色长期培养，一档一角色的规则不变，见 [角色存档与长期成长](角色存档与长期成长.md)。角色完成眷族加入任务后，才能从**当前所属眷族**招募合法队友。远征眷族队友偏向直接作战；锻造或经商眷族的队友可以较弱于战斗，但提供工艺、补给或交易方面的专业优势。队友随共同远征或专业活动持续成长，其能力留在玩家共享档案中的该眷族名册；角色转会时，旧眷族队友回到旧名册，新角色将来加入仍可招募。具体任务、成长和转会规则见 [眷族体系与成长](眷族体系与成长.md)。

- 队伍规模暂定 3 人，上限随原型确定。
- 每名成员带来自己的武器能力、技能与装备被动，队伍技能组合是协作与联动的来源。
- 角色在左右两侧呈现。多成员排列与换位规则待确定，当前 Demo 无战斗移动，见 [回合制战斗](../战斗系统/回合制战斗.md)。
- 联机时其他玩家携自己的长期角色加入；玩家角色与眷族队友的席位分配、队友控制权和人数上限待定，战斗规则与单人一致，见 [玩家主机联机](../联机/玩家主机联机.md)。

局外编队应展示每名队友的眷族归属、等级、战斗或专业定位、可用技能、装备所有权与出场成本。已培养的强队友可帮助新角色推进浅层；成熟的工匠或商贸成员则让新角色更快利用已建设的城市服务。奖励层级和出场成本可用于平衡，但不应抹掉玩家养成旧眷族的成果。专业成员是否占远征队伍席位、招募名额、后备队成长和队友伤亡规则待确认。

## 装备与技能配置

装备与技能的配置直接决定战斗中可用的技能：

1. 武器决定基础攻击手段，换武器会改变可用攻击技能。
2. 职业与转职提供技能，见 [职业与派生成长](../角色成长/职业与派生成长.md)。
3. 护甲与饰品提供常驻被动效果。
4. 技能之间通过关键词联动，配装的目标是组出有明确打法的组合。

出发前的配装同时是对本次探索与返程的预判：面对什么敌人、可能遇到什么机制、准备用什么手段处理，以及在战利品增加后如何安全返回。敌人机制的信息来源与情报系统待设计。

## 补给携带

补给在城市采购，占用背包格位，与战利品争夺同一空间，见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

- 补给品在道具栏以图标呈现，按各自定义对自己或敌人作用；使用消耗一次行动与一份物品。
- 携带量与预计深度需要玩家自行权衡：带多了没有空间装战利品，带少了走不深。
- 采购价格与库存受城市状态影响，见 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)。

## 待确认

- 队伍规模上限，以及单人探索时的难度适配。
- 眷族队友的招募成本、培养速度、伤亡与后备队成长。
- 背包格位数量、补给占位规则与升级方式。
- 配装方案的保存与快速切换方式。
- 情报系统：玩家如何在出发前了解目标楼层的敌人机制、材料来源与返程刷新风险。
