# 队伍编成与局外准备

状态：策划初稿，待实现。队伍构成、配装即组牌与补给携带为已确定方向；队伍规模、同行冒险者的获取方式与背包格位数值属于建议，需要原型验证。

## 局外准备的位置

局外准备是每次探索的起点，决定玩家带着什么进入地下城。由于局内资源不自动补满，出发时的选择直接决定能走多深，见 [资源与体力](../战斗系统/资源与体力.md)。

准备包含三件事：编成队伍、配置卡牌、携带补给。三者共用同一份背包与资金，互相挤占。

## 队伍编成

玩家的本体角色长期培养，一档一角色的规则不变，见 [角色存档与长期成长](角色存档与长期成长.md)。队友以同行冒险者的形式加入，在局外编成。

- 队伍规模暂定 3 人，上限随原型确定。
- 每名成员带来自己的武器卡、技能卡与装备卡，队伍卡池是协作与联动的来源。
- 成员的站位在编成时指定，战斗中可通过位移类卡改变，见 [卡牌战斗](../战斗系统/卡牌战斗.md)。
- 联机时队友位由其他玩家的角色顶替，战斗规则与单人一致，见 [玩家主机联机](../联机/玩家主机联机.md)。

同行冒险者的获取方式、成长方式与是否消耗资源维持待确认。

## 配装即组牌

装备与技能的配置直接决定战斗中可用的卡：

1. 武器决定基础攻击手段，换武器就是换掉一组卡。
2. 职业与转职提供技能卡，见 [职业与派生成长](../角色成长/职业与派生成长.md)。
3. 护甲与饰品提供常驻生效的装备卡。
4. 卡牌之间通过关键词联动，配装的目标是组出有明确打法的组合。

出发前的配装同时是对本次探索的预判：面对什么敌人、可能遇到什么机制、准备用什么手段处理。敌人机制的信息来源与情报系统待设计。

## 补给携带

补给在城市采购，占用背包格位，与战利品争夺同一空间，见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

- 补给品进入战斗后表现为补给卡，使用一次消耗一份。
- 携带量与预计深度需要玩家自行权衡：带多了没有空间装战利品，带少了走不深。
- 采购价格与库存受城市状态影响，见 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)。

## 待确认

- 队伍规模上限，以及单人探索时的难度适配。
- 同行冒险者的来源、雇佣成本与长期关系。
- 背包格位数量、补给占位规则与升级方式。
- 配装方案的保存与快速切换方式。
- 情报系统：玩家如何在出发前了解目标楼层的敌人机制。
