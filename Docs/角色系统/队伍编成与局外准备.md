# 队伍编成与局外准备

状态：策划初稿，待实现。队伍构成、装备与技能配置与补给携带为已确定方向；队伍规模、同行冒险者的获取方式与背包格位数值属于建议，需要原型验证。

## 局外准备的位置

局外准备是每次探索的起点，决定玩家带着什么进入地下城。由于局内资源不自动补满，出发时的选择直接决定能走多深，见 [行动与补给](../战斗系统/行动与补给.md)。

准备包含三件事：编成队伍、配置技能、携带补给。三者共用同一份背包与资金，互相挤占。

## 队伍编成

玩家的本体角色长期培养，一档一角色的规则不变，见 [角色存档与长期成长](角色存档与长期成长.md)。队友以同行冒险者的形式加入，在局外编成。

- 队伍规模暂定 3 人，上限随原型确定。
- 每名成员带来自己的武器能力、技能与装备被动，队伍技能组合是协作与联动的来源。
- 角色在左右两侧呈现。多成员排列与换位规则待确定，当前 Demo 无战斗移动，见 [回合制战斗](../战斗系统/回合制战斗.md)。
- 联机时队友位由其他玩家的角色顶替，战斗规则与单人一致，见 [玩家主机联机](../联机/玩家主机联机.md)。

同行冒险者的获取方式、成长方式与是否消耗资源维持待确认。

## 装备与技能配置

装备与技能的配置直接决定战斗中可用的技能：

1. 武器决定基础攻击手段，换武器会改变可用攻击技能。
2. 职业与转职提供技能，见 [职业与派生成长](../角色成长/职业与派生成长.md)。
3. 护甲与饰品提供常驻被动效果。
4. 技能之间通过关键词联动，配装的目标是组出有明确打法的组合。

出发前的配装同时是对本次探索的预判：面对什么敌人、可能遇到什么机制、准备用什么手段处理。敌人机制的信息来源与情报系统待设计。

## 补给携带

补给在城市采购，占用背包格位，与战利品争夺同一空间，见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

- 补给品在道具栏以图标呈现，按各自定义对自己或敌人作用；使用消耗一次行动与一份物品。
- 携带量与预计深度需要玩家自行权衡：带多了没有空间装战利品，带少了走不深。
- 采购价格与库存受城市状态影响，见 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)。

## 待确认

- 队伍规模上限，以及单人探索时的难度适配。
- 同行冒险者的来源、雇佣成本与长期关系。
- 背包格位数量、补给占位规则与升级方式。
- 配装方案的保存与快速切换方式。
- 情报系统：玩家如何在出发前了解目标楼层的敌人机制。
