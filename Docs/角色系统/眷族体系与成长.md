# 眷族体系与成长

状态：设计提案，尚未实现。确定方向包括眷族的入门任务、单角色单眷族、跨角色保留、队友成长，以及由锻造、经商等专业眷族经营城市服务。通过锻造和交易提升眷族等级是用户提出的可行方向；贡献计量、服务权限、加成数值与转会细则为建议，需验证。“眷族”为本项目统一术语；神明、组织名称与角色造型需使用项目原创内容。

## 定位与玩家体验

眷族是与角色等级、职业和装备并行的长期组织养成系统。世界里的工坊、商店、委托等城市服务也由各有身份的眷族经营；预计可有一两个锻造眷族，也可有专门经商的眷族。玩家先完成特定任务获得加入资格，加入后可通过符合该眷族专长的活动推进其成长。远征型眷族以讨伐和队友协作为主，锻造眷族通过制作与交付、经商眷族通过交易与商路活动成长。玩家可以转入其他眷族，也可以创建另一名角色，加入自己已经培养起来的旧眷族。

这条系统服务常规冒险的长期目标。不同眷族均可有成员与队友，但战斗力、职业构成和服务特长各不相同：锻造或经商眷族的战斗队友可以较弱，成员则在对应城市活动中获得更有价值的优势。部分长期成果还能为后续终局肉鸽解锁赐福候选；终局临时效果与眷族进度分别保存，见 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)。

## 眷族类型与城市分工

以下是功能定位示例，具体眷族数量、名称、服务范围和能力需逐个设计；专长可以交叉，不把所有锻造或交易都独占给某一个眷族。

| 侧重 | 可提供的常规服务 | 成员主要贡献 | 加入后的建议优势与取舍 |
| --- | --- | --- | --- |
| 远征与讨伐 | 情报、护送、战斗队友、讨伐委托 | 远征、怪物素材、救援与首领目标 | 队友与作战支援较强；锻造和交易保持基础能力 |
| 锻造与工艺 | 武器打造、修理、配方研究、特殊素材加工 | 完成制作、交付工艺委托、开发配方 | 更好的配方、工艺选择或材料利用；战斗队友偏工匠定位 |
| 商贸与补给 | 商店、订单、收购、补给与商路任务 | 成交、履行订单、建立货源 | 更好的采购渠道、谈判或补给方案；战斗队友偏护商定位 |

建议每类先做一个清晰样本，再考虑第二个同类眷族。两个锻造眷族可以分别擅长稳定量产与稀有材料工艺；两个商贸眷族可以分别擅长平价补给与高风险稀有货源。这样“加入哪一家”带来玩法选择，而城市基本服务对其他眷族成员仍可用。不同侧重不代表完全不能远征：工匠和商人也可探索，只是长期优势落在各自专业上。

**服务使用与成员归属是两件事。** 玩家即使加入远征眷族，也能向锻造眷族支付费用打造武器、在经商眷族的店铺交易。加入某眷族后，获得该组织的成员任务和专长加成。建议在某眷族实际使用锻造、交易等服务时，也为该眷族积累成长贡献，即使当前角色尚未加入它；成员贡献效率、专属权限与解锁内容另定。这样不同眷族都能在城市经济中成长，同时保留单角色单眷族的归属约束。非成员能推进到哪一级、合作关系是否跨角色共享，尚待确认。

## 加入资格与任务分层

每个眷族拥有自己的入门任务、进阶任务、队友、服务和发展方向。加入资格可以来自一项或多项条件；条件应在界面中明示，允许玩家有目标地准备。不同类型的眷族使用不同的任务语言，不强迫工匠或商人靠讨伐升级。

| 层级 | 内容示例 | 目的 |
| --- | --- | --- |
| 入门 | 讨伐哥布林、交常见素材、完成基础锻造订单、替店铺跑腿 | 让新角色及早加入一个团队，认识其专长与价值观 |
| 成员 | 指定楼层调查、协助队友、制作特定装备、履行供货合同 | 推动成员和据点成长，展示眷族分工 |
| 高阶 | 击败首领、打造高阶作品、建立重要商路，或达到等级与资金门槛 | 为强势眷族或高级职位提供明确目标 |
| 专属长期目标 | 处理眷族危机、建设设施、完成代表性工艺或跨地区贸易 | 解锁独特队友、服务、故事与终局赐福候选 |

“普通”与“强大”描述门槛及当前影响力，不预设后者的道德高低。入门友好的眷族也能通过长期培养发展壮大。远征任务可在常规地下城中完成；刷新怪物可用于普通讨伐计数，首领、特殊材料和唯一事件的奖励仍按各自领取规则处理。城市任务可在工坊或店铺完成，不要求每轮都进入地下城。任务进度、奖励和联机贡献都应可查询、可复核。

### 贡献如何转化为成长

建议每个眷族使用统一的长期等级与解锁展示，但**贡献来源按专长配置**。锻造眷族记录有实际材料与成品价值的制作、修理和工艺委托；经商眷族记录有效成交、供货订单和商路任务；远征眷族记录讨伐、情报与护送成果。界面明确显示本次活动给哪个眷族多少贡献、角色个人得到什么，以及下一级解锁的服务或成员。

贡献应在真实消耗和最终交付后结算，使用唯一记录防止重复领奖。建议普通买卖按净有效价值或订单完成度计贡献，避免同一件物品反复买卖刷级；制作同一低级配方也需收益递减或阶段上限。具体数值、非成员贡献的等级上限、多个角色的贡献如何叠加，均需经济原型验证。工坊服务的配方与素材规则由 [武器掉落与打造](../装备与物品/武器掉落与打造.md)维护；店铺价格、订单和库存由 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)维护。

## 成长的四个对象

| 对象 | 建议保存内容 | 归属与作用 |
| --- | --- | --- |
| 玩家角色 | 等级、职业、技能、个人装备、个人任务与当前眷族 ID | 每个角色自己的存档；同一角色同一时刻归属一个眷族 |
| 玩家档案中的眷族 | 每个眷族的声望、建设等级、服务设施、分类型贡献与解锁项 | 同一玩家的多个角色共享；转会或暂时无人加入时仍保留 |
| 眷族成员与队友 | 成员 ID、战斗或专业能力、装备归属、关系及可招募状态 | 属于该玩家档案中的对应眷族；可随远征或专业活动成长，转会不清零 |
| 当前远征 | 参与者、生命与道具、已走路线、怪物刷新及战利品 | 一趟下潜和返程的临时状态；完成结算后按归属回写 |

**建议的数据关系**：一个玩家档案可有多个角色存档和多个独立的眷族进度。每个角色存档只有一个当前眷族归属；一个眷族进度可关联多名该玩家的角色和该眷族的队友。角色存档不复制眷族成长数值，只持有稳定 ID 与个人贡献记录。这样新角色加入旧眷族时读到同一份成熟的设施和队友数据。

现有“一档一角色”保留为单个角色存档的粒度；玩家拥有多个角色档位时，档位上方增加共享档案。账号、云存档、离线档案以及联机时该共享档案的所有权规则尚需技术设计，见 [角色存档与长期成长](角色存档与长期成长.md)。

建议区分**世界中的眷族组织**和**玩家档案里与它相关的成长记录**。前者决定该工坊或店铺的身份、公共服务与故事；后者记录这名玩家积累的贡献、已解锁的会员服务、建设进度和队友。玩家到别人的联机世界使用服务时，交易由房间主机确认，贡献和会员解锁回写给各自的玩家档案。多人共同建设同一世界眷族的全服等级并非当前约定，若未来要做，需要单独设计世界所有权与同步规则。

## 招募与队友成长

队友由各眷族提供，可以是初始成员，也可以通过任务或设施解锁。招募前展示职业定位、当前能力、个人故事、远征成本和是否可以加入本次队伍；队伍上限、雇佣费与离队规则待确认。加入同一眷族提供招募资格，个别队友仍可有关系或任务要求。

队友参加地下城讨伐后获得经验、技能熟练度、个人关系或转职机会。建议把奖励与实际参与挂钩，并设置合理的后备队伍成长途径，避免玩家只能重复刷低层练每一名队友。队友的成长是长期记录，死亡与受伤规则单独设计；装备应标识个人所有、眷族库房所有或借用。

眷族整体成长建议来自符合专长的任务贡献、材料或商品流转、成员突破和设施建设。提高等级可扩充招募或专业岗位、开放高阶任务、补给或工坊服务，并解锁与其神明主题对应的终局赐福候选。工坊的师傅、商店的掌柜和护商队员也可以有长期成长与专属故事；他们是否作为可操作队友、服务能力如何随个人成长变化，待细化。每次升级要让玩家看见本部、服务和成员产生实际变化；数值、上限、材料与增益范围待平衡。

高等级战斗队友能帮助新角色认识地下城，也可能让低层战斗过于轻松。建议允许这种“老眷族带新人”的爽点，同时通过招募名额、队友出场成本和高级奖励的层级要求控制资源产出；具体限制不能抹去既有培养成果。专业眷族的跨角色爽点则是新角色可以直接使用已建设好的工坊、商路和成熟服务，但会员权限仍看该角色当前归属。跨角色继承的是眷族与其成员，角色自身等级、装备和个人职业仍按角色存档处理。

## 转入其他眷族

已确定方向：角色可以离开当前眷族，尝试加入另一眷族；原眷族的积累保留，未来的新角色可以加入。以下为建议的交接规则：

1. 在城市确认转会，展示资格、费用和将失去的当前访问权限。正在进行的远征先结算或结束，避免队伍归属在战斗中变化。
2. 旧眷族的等级、设施、已培养队友、已完成任务与已解锁内容留在玩家共享档案；旧眷族队友退出该角色的当前远征编成，回到自己的眷族名册。
3. 角色的个人等级、已学职业技能、个人装备与完成过的个人试炼继续属于角色。旧眷族授予的临时权限、借用装备和进行中的专属任务按事先公布的规则归还或暂停；不会抹掉完成记录。
4. 新眷族按自身入门条件接纳该角色；它的建设与队友从该眷族在玩家档案中的已有进度读取。若首次加入，则从该眷族的初始状态成长。
5. 角色或新建角色将来再加入旧眷族时，可使用保留的设施和已培养队友。个人专属资格仍单独检查。

角色是否可以随时转会、转会冷却或费用、跨眷族借队友、神明授予的永久能力能否在转会后继续使用，都尚未确定。旧眷族经营的普通工坊或店铺服务依然可购买；会员配方、折扣或岗位权限随当前归属验证。推荐先不做频繁切换收益的设计：任务奖励按唯一 ID 结算，借用物品按归属归还，已永久学习的普通职业技能不因转会删除。

## 眷族与终局赐福

眷族长期成长可解锁对应神明的终局赐福候选、起始契约、队伍支援或特殊试炼入口。解锁资格保存在玩家共享档案中；一趟终局肉鸽里实际抽到或选到的效果保存在该次挑战状态中。常规冒险以等级、装备、职业、眷族任务和队友成长为主要养成来源，终局挑战接收已经养成的角色和装备。

建议旧眷族已解锁的通用赐福候选在转会后继续进入终局可选池，使建设旧眷族始终有价值；当前所属眷族可提供主题权重或专属契约。具体哪些能力跟随当前归属、哪些作为共享解锁，需要在终局原型前定稿。这种候选解锁不保证每次终局挑战都能获得该赐福。

## 一段跨角色示例

角色甲加入旅神眷族，通过护送和返程任务培养两名队友并建设据点。甲在炉神眷族的工坊打造武器，正常支付费用，也为该锻造眷族积累贡献；之后甲转入炉神眷族，个人剑术与武器保留，旅神的设施和队友留在共享档案。甲此时可以接炉神工艺任务并使用会员配方，但仍能作为普通顾客使用旅神服务。角色乙新建后加入旅神眷族，能看到成熟据点并招募已成长队友；乙自己的等级、职业和装备从个人起点开始。旅神长期进度解锁的返程赐福进入终局候选池，角色甲与乙使用哪些候选由最终解锁规则决定。人物、神明与任务名称均为示例。

## 实现顺序与待确认

建议先验证一个远征眷族：加入任务、两名队友、团队贡献、一次队友成长和持久化。主游戏锻造与交易闭环成熟后，各加入一个小型专业眷族，验证在工坊制作、在店铺成交也能推动组织成长，以及非成员使用与成员加成的边界。随后验证转会与新角色加入旧眷族、共享档案和所有权。第二家同类眷族、复杂商路与专属工艺在首个样本好玩后再扩展。终局赐福只先登记解锁，不急于制作肉鸽挑战。

待确认：眷族的具体名单、每类数量与神明设定；专业眷族的成员、岗位和战斗队友规模；一个玩家可创建多少角色；共享档案边界；非成员贡献上限、会员加成与专业眷族的成长速度；高阶加入资格；队友成长和伤亡；眷族库房与借出装备；转会成本；跨眷族队友和技能的访问限制；联机中的贡献与共享数据所有权；终局赐福是否跨眷族可选。
