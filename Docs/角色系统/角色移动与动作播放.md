# 角色移动与动作播放

状态：第一阶段已实现四向行走与跑步的移动和播放。待机素材、攻击动作、可替换部件与武器挂接待实现。设计方向见 [角色创建与外观动画](角色创建与外观动画.md)。

## 分层结构

角色场景 `Scenes/Character/player_character.tscn` 按职责分三层，后续扩展落在对应层，互不干扰。

| 层 | 节点与脚本 | 职责 |
| --- | --- | --- |
| 输入与移动 | `CharacterBody2D` + `Scripts/Character/player_character.gd` | 读取输入、按角色档案的速度移动、判定朝向 |
| 表现 | `Sprite2D` + `Scripts/Character/character_visual.gd` | 按“动作 + 朝向”解析动作图、推进帧 |
| 碰撞 | `CollisionShape2D` | 脚下圆形碰撞体，半径来自角色档案 |

移动使用 `move_and_slide`，运动模式为浮动，俯视平面无重力。速度按加速度逼近目标值，避免瞬间启停。

## 动作解析

动作配置保存在角色档案的 `actions` 中，每个动作记录动作图路径、列数与帧率。表现层按朝向取行、按时间取列，从同一张图上取出单格。

动作图规格遵循 [俯视角色动作资产规范](../人物/俯视角色动作资产规范.md)：1024×1024，4 行×4 列，单格 256×256，行顺序为南、东、北、西，地面锚点在单格内 (128,224)。表现层把节点原点对齐地面锚点，因此角色节点的位置就是脚下投影中心，切换动作和朝向不会产生位移跳变。

当前动作与素材：

| 动作 | 素材 | 帧率 | 说明 |
| --- | --- | --- | --- |
| 待机 | 行走图首列 | 静帧 | 06-四向待机尚未制作，暂用行走序列首帧占位 |
| 行走 | `Assets/Characters/Lorn/07-俯视行走.png` | 6 FPS | 四向各四帧 |
| 跑步 | `Assets/Characters/Lorn/08-俯视跑步.png` | 8 FPS | 四向各四帧 |

## 输入与朝向

| 输入 | 行为 |
| --- | --- |
| WASD 或方向键 | 平面八方向移动 |
| 按住 Shift | 疾跑，速度与动作同时切换 |
| Esc | 暂时返回主菜单，暂停菜单实现后由其接管 |

移动支持八方向，视觉朝向先按四向表现：取输入向量的主导轴决定朝向，停止移动时保持最后朝向。八向素材与斜向表现待后续规格确定。

## 参数

洛恩当前参数记录在 `Scripts/Character/character_library.gd`：显示比例 0.9，碰撞半径 30，行走速度 150，跑步速度 300，加速度 1800。这些值按 1280×720 下的实际观感确定，属于可调参数；职业、装备与赐福影响移动时，在角色档案层面覆盖。

## 验证

`Tests/test_world_movement.gd` 覆盖出生点、四向朝向与取行、行走与疾跑速度、停止后回到待机、动作时间轴推进和围墙碰撞。执行 `godot --headless --path . --script Tests/test_world_movement.gd`。

`Tests/capture_world.gd` 输出实际渲染画面，环境变量 `TENSEI_CAPTURE_PATH` 指定输出位置，`TENSEI_CAPTURE_ACTION` 可为 walk 或 run。已检查 1280×720 下的角色比例、脚底锚点与地图关系。
