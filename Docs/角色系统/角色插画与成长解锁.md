# 角色插画与成长解锁

状态：设计草案，待实现。预设角色初始插画及通过升级、转职等成长事件解锁新插画为已确定方向；具体条件、展示交互和随机或自定义角色适配待细化。洛恩初始插画已获确认，素材与状态见人物文档；解锁系统待实现。

## 目标与参考

用精细的角色插画展示角色身份与成长阶段，让玩家在选择角色时看到鲜明的角色形象，并在长期培养中获得可见的成长反馈。

角色选择时的大幅角色原画展示参考《杀戮尖塔》。其官方 Weekly Patch 17 明确记录了 Ironclad 与 The Silent 角色选择画面的美术更新，见 [官方更新与配图](https://store.steampowered.com/news/posts/?appids=646570&enddate=1524827077)。该资料支持展示形式参考；升级、转职解锁插画是本项目的设计。

## 初始插画与成长形象

每个预设角色初始拥有一张插画，表现其冒险起点。以下为已提出的方向示例，具体角色名单与职业起点仍待确定：

| 初始身份或成长事件 | 插画表达 |
| --- | --- |
| 平民时期 | 朴素的衣着与日常用品，体现初出茅庐的身份 |
| 剑士学徒 | 偏学徒的服装与基础武器，表现尚在修行的阶段 |
| 法师学徒 | 学徒服饰与施法用品，表现魔法学习阶段 |
| 升级达到指定成长条件 | 可解锁新的阶段插画；具体等级及覆盖范围待设计 |
| 转职成为狂战士 | 可解锁同一角色的狂战士插画，体现职业变化与力量成长 |

各预设角色可拥有自己的初始身份，并沿其成长路线获得后续插画。插画覆盖哪些转职分支、是否每次升级都有奖励、每阶段数量和具体条件均待确认。

同一角色不同阶段应保留稳定的脸型、发色、种族特征和标志元素，通过服饰、装备、姿态、神情及构图体现成长。插画采用精细二次元表现，局内仍遵循非像素二维手绘方向。

## 展示与解锁建议

- 创建角色时展示预设角色的初始插画；读取存档时可展示该角色已解锁的成长插画。
- 达成条件后给出新插画提示，允许查看大图；是否自动切换展示图、允许自由选择旧图或设置独立收藏页待确认。
- 建议已解锁插画作为角色成长记录保留，转职变化后的展示资格与收藏资格分别处理，重置职业后的规则待定。
- 插画中的装备表现阶段主题，局内装备和部件由实际配置决定。插画解锁本身的属性奖励、皮肤联动或外观切换均待确认。

## 解锁与存档建议

插画定义记录稳定标识、适用预设角色、成长阶段、解锁条件、资源引用和显示信息。成长事件确认后，插画系统查询角色条件并登记解锁；重复事件、读档与断线恢复需避免重复发奖或重复通知。

建议角色存档记录已解锁插画标识及当前展示选择，资源由游戏内容或扩展提供。插画条件引用职业、等级等系统的正式状态；临时试用职业是否触发解锁需要明确配置。联机中依照已确认的成长结果更新个人解锁记录。账号共享收藏、其他存档继承和资源缺失回退待细化。

建议区分具体预设角色的身份标识与当前外观配置。随机、自定义角色如何匹配插画，以及预设角色修改外观后插画如何保持一致，需单独验证。候选包括按模板配置插画、分层组合或专门生成，均尚未定案；游戏运行时生成图片的服务与成本也未纳入当前承诺。

## 生图制作与后续验证

素材主要由生图模型制作。先确定角色基准，再基于参考图生成初始与成长阶段插画，检查身份一致性、职业特征、服装层次与装备结构。为角色名、说明和操作区域预留构图空间，文字由界面单独显示。分辨率、裁切安全区、背景层和多屏幕比例待界面原型确定。

建议首批制作同一预设角色的“剑士学徒 → 狂战士”两张插画，验证身份辨识、成长差异、角色选择展示、转职解锁、存档恢复与重复事件处理。此验证计划尚待实施。

插画资源可采用与其他内容一致的注册与依赖方式，为工坊预留入口；具体开放类型遵循 [发行与创意工坊](../平台与扩展/发行与创意工坊.md)。
