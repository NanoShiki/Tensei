# 主菜单

状态：首版已实现。项目暂名 **Project Tensei**。启动场景为 `Scenes/UI/main_menu.tscn`。

## 界面与交互

初版直接引用洛恩已确认的专注练剑原画，采用覆盖式缩放。左侧渐变遮罩承托项目标题和菜单，角色面部保留在右侧；底部显示当前插画对应的角色与阶段。1280×720 为基准，窗口最小 960×540。

- 继续旅程：恢复最近成功保存或读取的记录，底部显示角色名称及城市／楼层和步数；无档、损坏或不兼容时禁用并提示原因。某条记录最新代损坏时提示使用该条完整备份。
- 读取存档：先选择角色档案，再从该角色的可滚动记录列表读取；显示名称、楼层、移动步数、方向及本地保存时间。
- 开始旅程：洛恩模板可填写角色档案名称，提供「进入城市」与「战斗演练配置」；首次保存建立独立角色档案，各角色可有多条记录。独立演练不写存档，外观创建待实现。
- 设置：局内暂停窗口共用相同设置；音量和全屏即时生效，保存到 `user://menu_settings.cfg`，重新启动恢复。
- 退出游戏：二次确认，可取消。

- 试玩指南：右上可点击或按 F1 打开可滚动的六阶段指南，包含从新角色至第五层、技能目标、自由返程、刷新、手动保存及 GM 测试边界；主菜单只显示通用流程，不创建或读取个人旅程。Esc／F1 关闭后回到入口焦点。

支持鼠标、键盘方向键、Tab、Enter 和 Esc。弹窗打开后隔离主菜单键盘焦点，关闭后返回原焦点。菜单业务脚本为 `Scripts/UI/main_menu.gd`。

## 存档与成长插画

已确定规则：主菜单使用最新存档角色对应的当前成长插画；角色转职后可显示对应插画。

首版的 `apply_character_portrait(latest_character)` 接收含 `illustration_id` 的字典，交由 `menu_portrait.gd` 的可信插画目录解析。当前注册 `lorn.apprentice`，未知标识回退洛恩初始插画。直接引用项目已有图片，无重复资源。

继续旅程已连接本地存档服务，当前角色档案均使用洛恩模板并默认展示其初始插画。外观创建、成长解锁和新的插画注册尚待实现。界面不会读取存档中的任意资源路径。

## 第一阶段范围

当前可创建独立角色档案并进入城市整备，再从第一层出发，也可独立体验横版战斗演示。主菜单角色入口发出 `new_game_requested` 信号，「战斗演练配置」通过可点击窗口选择职业、等级、装备、敌人和队伍，再调用 `GameFlow.start_training(config)` 进入独立战斗。外观创建待实现。项目方向调整为回合制战斗后，原计划中的移动场景与多方向动画不再实现，见 [整体玩法设计](../游戏整体/整体玩法设计.md)。

## 验证与运行

项目使用 Godot 4.7，首版二维菜单采用 Compatibility 渲染器。用 Godot 导入项目后按 F6 运行场景，或 F5 运行主项目。

`Tests/test_main_menu.gd` 覆盖默认插画与未知标识回退、无存档状态、角色与设置弹窗、焦点恢复、音量及 Esc。执行 `godot --headless --path . --script Tests/test_main_menu.gd`。

`Tests/capture_main_menu.gd` 用渲染器输出画面检查，环境变量 `TENSEI_CAPTURE_PATH` 指定输出位置，`TENSEI_CAPTURE_PANEL` 可为 settings、character、saved、profiles、records、save，后两项准备 12 条记录用于长列表检查；`TENSEI_CAPTURE_SMALL=1` 使用 960×540。截图使用独立测试目录。

`test_demo_guide.gd` 验证主菜单、城市及战斗入口、重复窗口防护、关闭焦点、按当前记录显示进度、快捷键不穿透、不创建存档；960×540 主菜单及滚动指南已检查。完整回归 25 组 Godot、6 次独立进程恢复和16项 Python 通过。

「进入城市」调用 `GameFlow.start_character()` 创建角色并显示整备界面，再次出发保留同一角色身份；地图“保存并退出”落盘后才更新继续入口。继续通过 `GameFlow.continue_exploration()` 恢复原安全点。保存时机与异常恢复详见 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)。

局内暂停操作与验收统一见 [战斗操作与界面](../战斗与操作/战斗操作与界面.md)。暂停确认回到主菜单后恢复正常处理，读取旧记录仍恢复最近手动保存时点。
