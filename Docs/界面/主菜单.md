# 主菜单

状态：首版已实现。项目暂名 **Project Tensei**。启动场景为 `Scenes/UI/main_menu.tscn`。

## 界面与交互

初版直接引用洛恩已确认的专注练剑原画，采用覆盖式缩放。左侧渐变遮罩承托项目标题和菜单，角色面部保留在右侧；底部显示当前插画对应的角色与阶段。1280×720 为基准，窗口最小 960×540。

- 继续旅程：当前存档系统待实现，入口禁用。
- 开始旅程：展示洛恩角色入口，提示后续开放创建与旅程；当前未创建存档或进入游戏场景。
- 设置：音量和全屏即时生效，保存到 `user://menu_settings.cfg`，重新启动恢复。
- 退出游戏：二次确认，可取消。

支持鼠标、键盘方向键、Tab、Enter 和 Esc。弹窗打开后隔离主菜单键盘焦点，关闭后返回原焦点。菜单业务脚本为 `Scripts/UI/main_menu.gd`。

## 存档与成长插画

已确定规则：主菜单使用最新存档角色对应的当前成长插画；角色转职后可显示对应插画。

首版的 `apply_character_portrait(latest_character)` 接收含 `illustration_id` 的字典，交由 `menu_portrait.gd` 的可信插画目录解析。当前注册 `lorn.apprentice`，未知标识回退洛恩初始插画。直接引用项目已有图片，无重复资源。

最新存档读取、角色创建、继续游戏、成长解锁和新的插画注册尚待实现。后续存档服务读取最近存档，并向本接口提供该角色的展示标识；当前默认调用展示洛恩。界面不会读取存档中的任意资源路径。

## 第一阶段范围

最高目标为跑通一场横版卡牌战斗。当前已完成主菜单，后续接入战斗场景与角色数据装载。角色入口发出 `new_game_requested` 信号，当前用于后续衔接。项目方向调整为卡牌战斗后，原计划中的移动场景与多方向动画不再实现，见 [整体玩法设计](../游戏整体/整体玩法设计.md)。

## 验证与运行

项目使用 Godot 4.7，首版二维菜单采用 Compatibility 渲染器。用 Godot 导入项目后按 F6 运行场景，或 F5 运行主项目。

`Tests/test_main_menu.gd` 覆盖默认插画与未知标识回退、无存档状态、角色与设置弹窗、焦点恢复、音量及 Esc。执行 `godot --headless --path . --script Tests/test_main_menu.gd`。

`Tests/capture_main_menu.gd` 用渲染器输出画面检查，环境变量 `TENSEI_CAPTURE_PATH` 指定输出位置，`TENSEI_CAPTURE_PANEL` 可为 settings 或 character。已检查 1280×720 主菜单与 960×540 设置弹窗。
