## 集市订单与补给 Demo

城市“订单／补给”打开可滚动窗口。原创占位集市眷族经营两项一次性服务，每角色各一次：铁片供货订单消耗 2 铁片、获得 5 金币，对所有归属及未加入角色开放；完成后获得加入集市的资格。当前集市成员、共享等级至少 1 可支付 6 金币领取 3 瓶治疗药水，普通采购价为 9 金币。订单不发经验、不推进移动或委托；铁片与打造、材料委托共用库存。余额不足、已完成或探索中拒绝且资源不变。

每次实际订单为服务方集市贡献 +1，贡献 3／8 达等级 2／3，后续等级设施待开发。贡献按角色档案 ID 与订单 ID 去重，普通药水采购不计贡献。读取旧个人记录恢复当时订单和余额，再次支付完成旧订单仍只计一次共享贡献；不同角色的实际首次订单可累加。首次成交绑定共享玩家身份并保持原归属。共享缺失或所有者不符先拒绝交易；写入失败保留完整个人消耗与产出、完成标志和 `commerce_pending`，提示保存，恢复存储后从“眷族／编队 → 同步待提交成长／专业贡献”重试。未同步贡献阻止加入／转会。

验收：新角色用 GM 赢两场、自由返程，在城市保存“供货前” → 订单交付 2 铁片，金币 +5、集市贡献 1 → 眷族窗口加入或确认转会集市 → 订单窗口向下滚动购买会员礼包，金币 -6、治疗 +3、集市贡献 2 → 保存“订单后”。读取前一条并再次完成两项，共享贡献仍为 2；订单后记录恢复完成标志与资源。另一个角色首次供货使贡献达 3、等级 2。原晨行队友留城，巡守进度保留并暂停；转回晨行可继续。`test_commerce_orders.gd`、`test_commerce_recovery.gd` 覆盖真实 UI、资格、原子交易、跨角色与旧记录去重、混合工坊／商贸待同步、写入故障及异角色事件拒绝。32 组 Godot、6 次独立进程读写、21 项 Python 检查通过，960×540 窗口已检查；价格、归属选择与体验待用户验收。

## 当前城市委托 Demo

城市顶部“委托”打开可滚动列表。每条委托有三个独立状态：未接取、进行中、已交付；已交付不能重复接取或领奖。接取不扣款，只有城市能交付。

| 委托 | 条件 | 一次奖励 |
| --- | --- | --- |
| 初次讨伐 | 接取后赢得 3 场战斗，刷新战斗也计入；接取前胜利不追溯 | 6 金币、10 经验 |
| 工坊供货 | 持有 3 铁片，交付时消耗 3 铁片 | 8 金币、15 经验 |
| 守关队长讨伐 | 已击败第三层队长，接取时已有目标也有效 | 12 金币、25 经验 |
| 晨行成员巡守 | 当前晨行成员、共享眷族等级至少 2 可接取；接取后实际编队赢 5 场并回城 | 10 金币、20 经验 |
| 第五层勘察 | 交付队长委托后接取；接取后抵达第五层并回城，不追溯先前抵达 | 15 金币、15 经验 |

材料扣除、已交付标志、金币和经验共同成功；不足或重复提交不改变资源。铁片与打造共用持有量，玩家自行选择用途。任务进度、经验和资源随完整快照恢复，读取较早记录恢复其当时状态，个人奖励没有跨记录账本；眷族与卫士共享成长独立去重并保留当前积累。接取和领奖后仍须手动保存。等级规则见 [职业与派生成长](../角色成长/职业与派生成长.md)。这些委托与数值用于 Demo，真实编队胜利已推进共享眷族贡献；正式重复任务、失败和放弃仍待开发。

验收：F5 新建角色 → 委托，接取三项 → 出发，用 GM 赢三场 → 自选路线回城 → 城市委托。讨伐可领奖，金币 +6、经验 +10，等级 2、生命上限 40，当前生命保持；再次点击不重复发奖。交付材料消耗 3 铁片，累计 25 经验到等级 3；缺材料禁用。三层队长胜利后回城领奖累计 50 经验到等级 4。保存并退出再继续，已交付状态、等级与余额一致。`test_quests_growth.gd` 验证模型、窗口入口和存档；实际操作体验待用户验收。

### 成员巡守操作与边界

当前城市转会可保留晨行成员巡守的接取状态和计数；在炉心暂停推进及交付，转回晨行后继续。已领取的个人奖励保留。归属资格每次操作实时核验，炉心组织等级不能充当晨行资格。

晨行贡献达到 3 后共享组织等级 2，城市委托中的成员巡守按钮开放；未加入、档案不可用或等级不足显示资格原因。接受后只计实际卫士或游侠参加的胜利，成员倒下但本场参与仍计入；接取前胜利、单人、绕行和重复结算不增加，目标最多 5。第五场可以用 GM 正常达成，回城后领奖，重复点击无变化。出发多趟延续计数，个人安全点保存部分目标与已领奖状态。

验收：交付初次讨伐、加入并招募卫士；编队赢三场后回城，成员巡守应可接。接取后赢五场、回城领奖，金币 +10、个人经验 +20。保存“巡守4场”和“领奖后”，分别读取应恢复各自个人任务与奖励时点；共享卫士经验仍保持新值。未招募时的胜利和绕行不推进目标。新角色必须先取得自己的加入资格，加入旧等级2眷族后可直接接取。

`test_familia_quests.gd` 覆盖资格／等级锁定、真实 UI 接取、接取前不追溯、单人／绕行、计数、GM第五场、重复拒绝、部分与已领奖磁盘恢复、旧记录和越界拒绝；日志工具检查组织条件、编队计数与奖励。二十组 Godot 专项、六次独立进程恢复和十二项 Python 检查通过，960×540 委托窗口已检查；用户体验与奖励平衡待验收。

### 第五层勘察与完整成长验收

交付守关队长讨伐后，在城市委托向下滚动接取第五层勘察；先前已到第五层也需接取后再次抵达。地图与城市显示目标进度，返程和新远征保留接取后的最高值（上限 5）；抵达只完成目标，不自动发奖。回城领奖一次金币 +15、经验 +15。五条 Demo 委托全部交付累计 85 经验，等级 5／生命上限 52，升级保留当前生命，随后旅店休整。单人可做勘察；达到当前经验上限需要额外完成成员巡守。

验收：三条入门委托 → 加入眷族并编队至组织等级 2 → 接取成员巡守与勘察 → 出发至第四层保存一条 → 继续至第五层并自由返程 → 委托领奖 → 保存另一条。读取第四层记录应恢复目标 4 与旧个人奖励，读取领奖后记录应恢复已交付和等级 5；共享成长保持最新。重复领奖与探索中领奖拒绝且资源不变，旧记录补未接取／零进度。

委托操作经 `GameFlow.quest_service` 每次重新读取共享档案并核对归属；窗口提供“刷新委托与共享资格”。档案缺失时不沿用开窗时等级，恢复后可在同一窗口刷新；未加入显示实际状态，已接取／已交付优先显示任务状态。`test_depth_goal.gd` 从新角色实际完成五条任务，含真实按钮与 GM、途中／领奖后磁盘恢复；日志检查抵达层数与目标公式、城市奖励、资格和去重。23 组 Godot、6 次独立进程恢复、15 项 Python 检查通过，960×540 委托窗口已检查。体验与平衡待用户验收。

## 已确定方向

城市与地下城均可提供任务接取和交付地点。城市商店、收购与补给可由经商眷族经营，预计可以有专门的经商眷族，具体数量待规划。玩家在其店铺交易、完成订单或商路任务，建议可推动该眷族长期成长；加入后可获得与经商相关的额外权益。地下城交接受到更多限制，安全楼层承担阶段性服务。地下城物资售卖价格更高、玩家出售物品的收购价更低，形成用收益换取途中便利的有损交易。

## 任务规则建议

每个任务应说明发布者、接取条件、目标、进度、交付地点、奖励和失败条件。初期可研究讨伐、材料收集、探索、护送和职业试炼。

进度跨城市与地下城延续。任务条件满足、可交付和奖励已领取应分别呈现。材料收集任务要说明检查持有数量还是累计获取数量，以及交付时是否消耗材料。

眷族提供加入资格任务和分级长期委托：远征型眷族可要求哥布林讨伐、常见素材或首领；锻造眷族可要求制作与交付；经商眷族可要求跑腿、供货、资金或商路经营。强势眷族还可设置等级、资金或代表性成果门槛。对应贡献推动服务、成员与设施成长，详见 [眷族体系与成长](../角色系统/眷族体系与成长.md)。职业试炼在常规冒险中结算；终局赐福候选解锁与临时生效分开，见 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)。

## 交易决策

玩家可以在安全楼层高价购买补给以继续深入，也可以低价出售部分战利品换取资金或空间。返回城市通常提供另一种资源安排选择，其收益需要与返回成本共同衡量。

第五层入口已接有限休整和途中采购，售价高于城市，不提供委托交付或物资收购；位置、具体价格与验收统一见 [休整站 Demo](../世界与探索/城市与地下城探索.md)。城市集市订单已形成可玩切片，收购与商路任务仍待开发。

## 经商眷族与服务成长

不同经商眷族可以提供不同货源、订单与服务侧重，例如一家经营稳定平价补给，另一家处理稀有材料和高风险商路。玩家即使未加入，也可在这些店铺正常购买和出售。完成有效成交、供货订单或商路任务，为经营它的眷族积累贡献；加入后可获得更好的采购渠道、会员订单、有限折扣或更宽的补给选择。具体权益、价格上下限和经济回收待验证，避免商贸眷族因纯数值折扣成为唯一最优归属。

贡献建议按净有效交易价值与订单交付记录，不按点击次数或同一商品反复买卖的流水累加。交易界面展示价格、库存、该笔交易带来的眷族贡献及当前会员权益。商贸队友可偏护商、寻货与补给支援，其直接战斗能力可以弱于远征队友，但不应让加入商贸眷族的主角失去正常下潜能力。组织等级、跨角色保留及转会时会员权益的处理见 [眷族体系与成长](../角色系统/眷族体系与成长.md)。

眷族设施或任务成果可以解锁补给、折扣或指定配方；实际库存、售价、收购价和交付奖励仍由常规交易与任务规则确定。终局挑战如果设置本局商店，其临时效果仅作用于该模式。是否展示城市参考价格待确认。

## 批量补给与铁片出售 Demo

城市“批量补给／出售”打开数量窗口，每笔选择 1–99；治疗药水 3 金币／瓶、灼烧 4 金币／瓶、铁片普通收购 1 金币／片。按钮展示实际数量与总价，改变数量同步更新；余额／库存不足禁用，执行时再次核验并一次性扣除和发放。出售消耗同一铁片库存，影响打造、供货和材料委托；目前只收购铁片，武器与药水出售待开发。原一瓶快捷采购继续可用。收购价为可调 Demo 参数。
