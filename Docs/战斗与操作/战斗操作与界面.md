# 战斗操作与界面

状态：2D 简化回合制 Demo 已实现。规则见 [回合制战斗](../战斗系统/回合制战斗.md)。

## 操作

1. 点击技能或药水图标，或按数字键 1–6 选中。
2. 点击高亮的合法角色执行。攻击和灼烧药水选敌方，闪避／回气选当前成员，治疗药水选存活受伤己方。
3. 执行消耗一次行动，伤害或恢复反馈后刷新界面。
4. 点击右下结束回合，或按空格推进。默认每回合只能行动一次，特殊效果可增加次数。

选中阶段按右键或 Esc 取消，不消耗行动；再次点击同一图标也可取消。执行阶段锁定输入防止重复结算。返回主菜单使用明确按钮；有技能选中时 Esc 先取消；未选中或反馈期间 Esc 打开暂停。

## 界面分区

- 顶部：楼层、轮数、固定先攻顺序及当前行动者。
- 中央：己方在左朝右、敌方在右朝左，实际编队展示洛恩、卫士与游侠，双人演练展示洛恩与卫士，姓名、血条、HP 和 AC；浮动显示伤害、恢复与未命中。
- 左下装备：当前木剑／铁剑、布衣和属性；铁剑打造后自动装备，城市“工坊／装备”可选择持有武器。
- 中下技能：职业名称、随当前成员职业变化的第二技能、紧凑图标及名称，显示统一剩余行动次数；悬停说明效果与不可用原因。
- 中下道具：治疗药水与灼烧药水，分别展示库存，使用后扣减。
- 右下：结束回合按钮与快捷键提示。

单敌武器技能选中后显示命中率；双敌分别高亮，悬停目标展示该敌人 AC 对应的命中率；药水显示效果规则，直接对目标作用。无 3D 环境操作。界面采用 1280×720 设计画布，按窗口等比缩放，960×540 保留所有分区。

## 状态与结果

不可用按钮置灰，选中和合法目标高亮。双敌分别显示姓名、生命和目标按钮，最多五名先攻紧凑排列；倒下敌人不可选且跳过回合，全部敌人倒下才胜利。己方零行动时结束回合仍可用。敌方行动和反馈期间不可出招。战斗结束禁用技能、道具及结束回合，展示胜负与剩余资源。

探索战斗结算后返回同层地图；独立演示可重开。局内暂停与设置已接入；双人演练按固定先攻切换当前成员，城市编队已接入。按键重绑、手柄和联机等待提示待实现。

## 试玩指南

城市、地图和战斗提供“指南 · F1”，也可按 F1 打开，Esc／F1 关闭。滚动查看六阶段流程和操作：准备、首趟委托成长、可选打造、队长、眷族成员及第五层。当前任务、材料、等级与组织资格按打开时状态只读展示；不会推进步数、行动、随机数、奖励或保存。重新打开查看最新进度，指南打开时禁止底层技能、结束回合和背包快捷键；异步动作中不开窗。

## 探索背包

地图和城市顶部点击“背包 · B”，或按 B 打开；窗口展示装备、金币、材料和药水，可在受伤且有库存时使用治疗药水。B／Esc 关闭。背包为独占窗口，打开时不操作底层地图；战斗、回城摘要没有背包入口，战斗用药沿用目标选择和行动规则。详细约束见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

## 探索返程与回城

地图显示移动总步数、已到访及下一步可选战斗节点的刷新剩余步数或怪物在场状态。点击“向上返回”后，高亮全部合法向上分支，允许选择未走过的节点；分叉处直接点击地图选择，只有唯一目标时提供快捷按钮。向上途中可随时点“继续深入”，重新开放已走过的向下路线；位于旧层出口时通过“进入第 X 层”前往下一层。切换方向不计步。其他未到访节点仅显示“未知”，保留位置与连线，悬停及进度条均不泄露详情；靠近但未到访的节点离开后重新隐藏。切换方向同步更新下一步可见范围。节点到访标记与怪物状态独立显示，营地和补给标明领取情况。每步先扣刷新倒计时再检查遭遇；剩 1 步目标的悬停提示明确说明进入会遇敌。

返程遇敌正常进入战斗，胜利后返回地图并继续返程。营地和补给按节点首次领取，刷新不重置领取记录。第一层入口回城显示单次摘要；“放弃并回主菜单”不产生成功摘要。地图“保存并退出”可在当前角色下新增命名记录或确认覆盖选定记录；主菜单“读取存档”按角色与记录两层选择，“继续旅程”恢复最近保存或读取的记录；战斗中及回城摘要不保存；摘要可进入城市整备，购买药水、打造铁剑并保存城市状态，详细规则与验收见 [地下城推进与怪物之宴](../世界与探索/地下城推进与怪物之宴.md)。

## 局内暂停与设置 Demo

城市与地图右下“暂停 · Esc”、战斗顶部“暂停”打开独占窗口；Esc 也可打开。已选技能的第一次 Esc 先取消选中，第二次暂停；其他背包／委托等窗口优先处理 Esc，GM 菜单展开时先收起 GM。暂停停止场景处理、敌人等待计时和浮字 tween，保留当前行动、目标选择、生命、药水、随机数、节点及移动刷新。反馈期间也可暂停，继续后完成同一次反馈或依原先攻继续敌人行动。窗口禁止底层技能、结束回合及 GM 修改。

“继续旅程”、Esc 或右上关闭恢复；回主菜单先确认，取消仍保持暂停，确认放弃未保存的个人进度，共享组织成果保留。暂停不自动保存，城市／地图安全点仍通过原保存入口。音量与全屏即时生效，与主菜单共用 `user://menu_settings.cfg`；写入失败显示原因并保留已生效设置，进度不受影响。外部释放窗口或离开场景清理暂停，避免后续菜单无法操作。

验收：F5 城市／地图点击暂停，等待后继续，资源、步数与刷新保持；战斗选技能后 Esc 取消，再按暂停。敌人提示或浮字期间暂停并等待，应停止动画及敌人攻击；继续完成原动作，不重复消耗。调音量后返回主菜单打开设置应保持，退出确认取消后继续。`test_pause_menu.gd` 验证实际按钮、Esc、真实双敌计时和浮字冻结、随机数与资源保持、设置持久化／写入失败、GM／快捷键锁定、外部释放及确认离开；自动日志检查暂停前后完整快照不变。用户操作体验待验收。
