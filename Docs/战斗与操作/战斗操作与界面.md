# 战斗操作与界面

状态：2D 简化回合制 Demo 已实现。规则见 [回合制战斗](../战斗系统/回合制战斗.md)。

## 操作

1. 点击技能或药水图标，或按数字键 1–6 选中。
2. 点击高亮的合法角色执行。攻击和灼烧药水选敌方，闪避、回气和治疗药水选自己。
3. 执行消耗一次行动，伤害或恢复反馈后刷新界面。
4. 点击右下结束回合，或按空格推进。默认每回合只能行动一次，特殊效果可增加次数。

选中阶段按右键或 Esc 取消，不消耗行动；再次点击同一图标也可取消。执行阶段锁定输入防止重复结算。返回主菜单使用明确按钮；当前 Esc 仅取消选择。

## 界面分区

- 顶部：楼层、轮数、固定先攻顺序及当前行动者。
- 中央：左侧洛恩朝右、右侧哥布林朝左，姓名、血条、HP 和 AC；浮动显示伤害、恢复与未命中。
- 左下装备：木剑、布衣和当前属性，只展示装备，换装功能待实现。
- 中下技能：常驻紧凑图标及名称，显示统一剩余行动次数；悬停说明效果与不可用原因。
- 中下道具：治疗药水与灼烧药水，分别展示库存，使用后扣减。
- 右下：结束回合按钮与快捷键提示。

武器技能选中后显示命中率；药水显示效果规则，直接对目标作用。无 3D 环境操作。界面采用 1280×720 设计画布，按窗口等比缩放，960×540 保留所有分区。

## 状态与结果

不可用按钮置灰，选中和合法目标高亮。己方零行动时结束回合仍可用。敌方行动和反馈期间不可出招。战斗结束禁用技能、道具及结束回合，展示胜负与剩余资源。

探索战斗结算后返回同层地图；独立演示可重开。暂停菜单、按键重绑、手柄、多成员切换与联机等待提示待实现。

## 探索返程与回城

地图显示移动总步数、各战斗节点的刷新剩余步数或怪物在场状态。点击“开始返程”后，高亮全部合法向上分支，允许选择未走过的节点；分叉处直接点击地图选择，只有唯一目标时提供快捷按钮。每步先扣刷新倒计时再检查遭遇；剩 1 步目标的悬停提示明确说明进入会遇敌。

返程遇敌正常进入战斗，胜利后返回地图并继续返程。营地和补给按节点首次领取，刷新不重置领取记录。第一层入口回城显示单次摘要；“放弃并回主菜单”不产生成功摘要。存档和永久收益尚未接入，详细规则与验收见 [地下城推进与怪物之宴](../世界与探索/地下城推进与怪物之宴.md)。
