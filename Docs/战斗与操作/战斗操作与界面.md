# 战斗操作与界面

状态：第一阶段原型已实现点击出卡、点选目标、右键或 Esc 取消、时间轴与资源分区。数字键快捷、空格结束行动、Tab 机制说明、背包与推进图仍待实现。战斗规则本身由 [卡牌战斗](../战斗系统/卡牌战斗.md) 维护，本文负责操作与界面呈现。

## 操作方向

战斗以鼠标操作为主，键盘提供快捷方式。玩家手动指挥全部队员，不存在自由移动与实时输入。

| 输入 | 目标行为 | 待细化部分 |
| --- | --- | --- |
| 鼠标点击卡牌 | 选中一张卡，显示消耗、耗时与作用范围 | 选中态与预览的表现强度 |
| 鼠标点击目标 | 对选中卡指定目标，再次确认后打出 | 单体、范围与无需目标的卡的确认差异 |
| 鼠标右键或 Esc | 取消当前选择 | 与暂停菜单的层级关系 |
| 数字键 1 至 9 | 快速选中对应卡位 | 卡位数量与排序规则 |
| 空格 | 结束当前单位的行动 | 是否允许保留行动 |
| 按住 Tab | 查看敌人机制、状态与关键词说明 | 信息密度与分页方式 |
| B | 打开背包，查看补给与战利品 | 战斗中可否整理背包 |
| M | 打开地下城推进图 | 显示范围与已揭示信息 |
| Esc | 打开暂停菜单 | 单人与联机的时间规则 |

鼠标侧键与手柄仅作为可选绑定，主要玩法必须通过常规键鼠完成。按键重绑待实现。

## 界面分区

建议的横版战斗界面分区，具体布局随原型调整：

- **战场**：画面中部，我方在左、敌方在右，按前后排排列，显示血条、状态图标与蓄力提示。
- **行动时间轴**：画面上方，展示未来若干次行动顺序，敌人的蓄力攻击在此处提前可见。这是战斗内最重要的信息，需要保证可读性。
- **卡牌区**：画面下方，展示当前行动单位的全部可用卡。资源不足或次数耗尽的卡保持可见并置灰，让玩家随时了解自己的完整选项。
- **资源区**：展示体力、MP、生命与补给数量。体力接近疲劳阈值时需要明确提示，规则见 [资源与体力](../战斗系统/资源与体力.md)。
- **队伍区**：展示各成员状态与站位，点击可查看其卡牌。

## 表现要求

- 敌人的蓄力、可打断窗口与作用范围必须清晰可读，玩家的应对决策依赖这些信息。
- 卡牌的消耗、耗时与关键词在选中前即可看到，避免试错式操作。
- 资源变化、状态附加与关键词触发需要明确反馈，区分一次性效果与持续效果。
- 不同武器与职业的卡应具备可识别的视觉差异，稀有度通过图形、文字与颜色共同表达。

## 菜单与联机

单人模式建议支持 Esc 暂停。Listen Server 联机中建议 Esc 打开本地菜单并让战斗继续，全队暂停机制待确认。背包与推进图在联机中是否暂停时间，也需要分别确定单人与联机行为。

以上菜单行为属于建议，具体决策与 [玩家主机联机](../联机/玩家主机联机.md) 同步维护。

- 联机时的操作等待、超时处理与行动提示。
- 按键重绑与手柄支持范围。
