# 战斗操作与快捷交互

状态：策划初稿，待实现。下表记录项目输入方向，具体动作分配与菜单细节待细化。

## 动作体验

参考 Hades 的即时动作体验，强调移动、瞄准、攻击节奏和快捷决策。玩家主要通过键盘移动与鼠标定位完成操作，武器、职业和赐福共同影响战斗方式。

## 已确定输入方向

| 输入 | 目标行为 | 待细化部分 |
| --- | --- | --- |
| WASD | 角色移动 | 移动与攻击、施法的互相限制 |
| 鼠标位置 | 提供瞄准、技能或道具的目标位置 | 地面目标、方向与单位目标的选择方式 |
| 鼠标左键、右键 | 承担主要攻击、技能或道具使用 | 根据当前装备和选择状态分配动作 |
| 按住 Tab | 打开快捷选择，可覆盖武器、道具及其他常用动作 | 选择层级、确认与取消方式 |
| 数字键 1、2、3、4、5、6、7 等 | 快捷栏切换 | 栏位数量及切换后的使用行为 |
| B | 打开背包 | 战斗中打开时的输入处理 |
| M | 打开地图 | 显示范围和交互方式 |
| Esc | 打开暂停菜单 | 单人与联机的时间规则 |

鼠标侧键仅作为可选绑定，主要玩法必须通过常规键鼠完成。Tab 快选的内容保留扩展空间，以支持熟练玩家快速组合操作。

## 快捷选择建议

Tab 可采用轮盘或分类面板；建议按住显示、鼠标指向条目、松开确认选择。具体方案待原型验证。数字键优先表达选择对应栏位，直接使用模式另行确定。

快捷界面需要区分选择物品、装备切换和执行动作。鼠标操作界面时，应明确处理瞄准与攻击输入，防止选择动作意外触发消耗。

## 菜单与联机

单人模式建议支持 Esc 暂停世界。Listen Server 联机中建议 Esc 打开本地菜单并让共享世界继续运行；全队暂停机制待确认。Tab、背包和地图是否减速或暂停，也应分别确定单人与联机行为。

以上菜单行为属于建议，具体决策与 [玩家主机联机](../联机/玩家主机联机.md)同步维护。

## 表现与待确认事项

准星、攻击预警、技能范围、快捷栏数量、选中状态和冷却提示应保持清晰。不同武器与职业应具备可识别的动作节奏。

待确认：闪避或冲刺、交互、额外技能键、按键重绑、手柄支持、镜头形式、目标辅助、攻击取消规则和技能资源。职业与物品关系见 [职业与派生成长](../角色成长/职业与派生成长.md)、[背包与物品流转](../装备与物品/背包与物品流转.md)。
