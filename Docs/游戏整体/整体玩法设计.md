# 整体玩法设计

状态：策划初稿，待实现。本文记录已确定方向；标注“建议”“示例”和“待确认”的内容用于后续讨论。

## 游戏定位

日式西幻题材的多人地下城动作冒险游戏。玩家以城市或家园为生活与准备中心，进入地下城战斗、收集、完成任务和发展职业，并携带所得返回城市继续成长。

美术采用日式西幻方向。项目重点参考《在地下城寻求邂逅是否搞错了什么》（简称《地错》）与《刀剑神域》，以《无职转生》为补充，同时借鉴 D&D 对职业能力、条件和规则边界的完整表达。

《33 Immortals》是后续操作模式与二维资产形态的重点参考，《Jotun》补充手绘表现和多方向动画的参考。项目采用非像素、纯二维手绘资产，保持类似《以撒》的俯视角平面移动，并借鉴 Hades 的即时动作体验。可用“二维资产形态的 Hades”理解期望体验；这属于项目定位类比，原作之间的创作影响尚未核实。具体键位采用本项目约定，美术流程见 [美术风格与素材制作](../美术/美术风格与素材制作.md)。

《刀剑神域》已纳入重点参考范围，具体篇章、设定和机制的借鉴范围待后续细化。各模块采用具体设计时，应记录参考依据与本项目的取舍。

神明、眷属与眷族关系承载肉鸽机制的世界观表达。赐福、神谕、契约和试炼将随机成长机会与冒险生活关联，神明提供力量的表达参考 Hades。具体设定与跨系统规则统一维护在 [全局肉鸽机制](../肉鸽系统/全局肉鸽机制.md)。

## 连续冒险

“局内”指进入地下城期间，“局外”指回到城市或家园期间。这两个词仅描述活动环境，玩家的角色、携带物品和长期成长贯穿往返过程。

玩家可以根据危险、补给和收益决定继续深入或中途返回。主动返回城市后，尚未消耗、交付或出售的物品仍由玩家持有。转场本身不清空背包，也不自动结束所有任务。

建议的体验流程：城市接取委托并准备装备 → 进入地下城 → 战斗收集并遭遇肉鸽选择 → 在安全楼层补给或交接 → 继续深入或返回 → 打造装备、推进职业并准备下一次探索。每个阶段允许承接先前进度。

## 参考资料及使用范围

- [《地错》官方世界观用语](https://danmachi.com/danmachi/special/index.html)：用于理解冒险者、地下城和支援者等设定语境。项目重点吸收地下城冒险与城市生活相互支撑的体验。
- [《无职转生》官方角色介绍](https://mushokutensei.jp/character/)：提供魔术学习、剑士修行等角色成长参考。项目具体职业树和解锁条件由自身玩法决定。
- [D&D 2024 基础规则：职业](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes)：用于核对职业原型和专精关系，职业候选整理见职业文档。即时动作战斗规则需要按本项目设计。

以上资料用于参考研究。本文及模块文档中的项目方案和示例均为本项目设计提案，原作细节仅在有明确来源时作为事实描述。

## 后续设计问题

- 单人体验、联机人数上限与队伍协作强度。
- 死亡、倒地、救援和团灭的损失规则。
- 地下城地图刷新、探索进度保存及再次进入方式。
- 临时肉鸽效果的生命周期与长期成长的分界。
- 首个可玩版本的职业、武器、敌人与楼层范围。
