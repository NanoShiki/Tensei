# 整体玩法设计

状态：策划初稿，待实现。本文记录已确定方向；标注“建议”“示例”和“待确认”的内容用于后续讨论。

## 游戏定位

日式西幻题材的多人地下城回合制战斗冒险游戏。玩家以城市或家园为生活与准备中心，带着队伍和补给进入地下城，通过横版回合制战斗持续深入，并携带所得返回城市继续成长。

局内采用横版 2D 简化回合制：我方左侧、敌方右侧，选择技能或道具图标后点选目标。每个角色每回合默认行动一次，特殊技能或效果可增加行动次数。底部按装备、技能、道具与结束回合分区，见 [回合制战斗](../战斗系统/回合制战斗.md)。

地下城预计几十层，每一层拥有一张入口、分支节点与出口组成的地图。生命与药水跨战斗延续，玩家在路线、休整与战斗之间权衡，见 [行动与补给](../战斗系统/行动与补给.md)。

游戏以一档一角色的长期培养为核心：创建预设、自定义或随机角色，通过探索获得武器、转职和技能，逐步提升实力并攻略更深层地下城。浅层持续提供资源，成熟角色可重复探索、联机护送新手或挑战终局。存档与成长规则见 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)。

目标上线 Steam，联机基于 Steam 并采用 Listen Server，同时支持创意工坊。后续实现需预留平台接入、内容注册、版本兼容与存档扩展边界，见 [发行与创意工坊](../平台与扩展/发行与创意工坊.md)。

## 参考方向

美术与世界观采用日式西幻，以《地错》与《刀剑神域》为重点、《无职转生》为补充。《地错》的地下城设定提供了本作最重要的体验基准：地下城危险、补给有限、深入需要付出代价。

地图参考《杀戮尖塔》的节点路线表达；战斗参考 DND、博德之门的回合组织与技能栏交互，按 2D 横版进行简化。高低差、跳跃、投掷轨迹、地形表面与物理环境互动不纳入当前规则。药水直接对自己或敌人施加各自效果。

《Jotun》与《33 Immortals》继续作为二维手绘美术参考。具体数值、技能与先攻采用原型方案，待游玩评估。

神明、眷属与眷族关系承载肉鸽机制的世界观表达。赐福、神谕、契约和试炼将随机成长机会与冒险生活关联，神明提供力量的表达参考 Hades。局内赐福直接作用在技能上，具体设定与跨系统规则统一维护在 [全局肉鸽机制](../肉鸽系统/全局肉鸽机制.md)。

## 核心循环

“局内”指进入地下城期间，“局外”指回到城市或家园期间。这两个词仅描述活动环境，玩家的角色、携带物品和长期成长贯穿往返过程。

```text
局外准备 → 进入地下城 → 连续战斗与事件 → 资源持续消耗 → 继续深入或返程 → 带回所得 → 强化与再准备
```

局外准备包括编成队伍、配置装备与技能、采购并携带补给，见 [队伍编成与局外准备](../角色系统/队伍编成与局外准备.md)。局内按楼层连续推进，资源持续消耗并通过节点有限补给，收益随深度上升，见 [地下城推进与怪物之宴](../世界与探索/地下城推进与怪物之宴.md)。

当前 Demo 提供逐层深入。主动返程、中途避战与撤退路线在后续阶段设计，这些机制的接口在推进文档中预留。

## 深度来源

当前规划的深度来源：

| 来源 | 作用 |
| --- | --- |
| 配装组合 | 技能、装备与赐福之间形成配合，不同武器、职业与赐福组合出不同打法 |
| 行动时机 | 固定先攻顺序下，决定本回合唯一一次行动的用途 |
| 资源规划 | 生命与药水跨战斗结算，每场战斗都要决定投入多少 |
| 敌人机制 | 敌人具备明确机制，需要对应手段处理，出发时的配装即是对本次探索的预判 |

站位与阵型作为补充来源，具体范围在横版战斗原型中确定。

## 终局方向

为最深层制作流程较长的专门地图，支持成熟角色单人或联机重复挑战。此前各层首领提升到统一的终局强度档位，并随机出现、附加随机效果，结合肉鸽机制形成高难度变化。具体地图、强度解释及待确认事项见 [深层终局挑战](../世界与探索/深层终局挑战.md)。护送新手与继续普通楼层探索同样是成熟角色的可选活动。

## 参考资料及使用范围

- [《地错》官方世界观用语](https://danmachi.com/danmachi/special/index.html)：用于理解冒险者、地下城和支援者等设定语境。项目重点吸收地下城冒险与城市生活相互支撑的体验，以及地下城的消耗性与危险感。
- [《无职转生》官方角色介绍](https://mushokutensei.jp/character/)：提供魔术学习、剑士修行等角色成长参考。项目具体职业树和解锁条件由自身玩法决定。
- [D&D 2024 基础规则：职业](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes)：用于核对职业原型和专精关系，职业候选整理见职业文档。

以上资料用于参考研究。本文及模块文档中的项目方案和示例均为本项目设计提案，原作细节仅在有明确来源时作为事实描述。

## 后续设计问题

- 单人和多人难度适配、联机人数上限与队伍协作强度。
- 死亡、倒地、救援和团灭的损失规则。
- 返程、避战与撤退路线的具体机制。
- 临时肉鸽效果的生命周期与长期成长的分界。
- 首个可玩版本的职业、技能、敌人与楼层范围。
