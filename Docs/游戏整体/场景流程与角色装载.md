# 场景流程与角色装载

状态：第一阶段已实现主菜单进入城市庭院的流程。角色创建与存档读取待实现，当前由预设角色目录直接提供档案。

## 流程职责

自动加载单例 `GameFlow`（`Scripts/Core/game_flow.gd`）是场景之间唯一的切换入口，同时保存当前进行中的角色档案。主菜单、地图场景都通过它切换，避免各场景互相直接引用。

当前流程：启动 → 主菜单 `Scenes/UI/main_menu.tscn` → 「开始旅程」展示洛恩入口 → 「进入世界」调用 `GameFlow.start_new_game("lorn")` → 装载角色档案并切换到 `Scenes/World/city_courtyard.tscn` → 地图在出生点实例化角色。

`GameFlow.return_to_menu()` 清空当前角色档案并切回主菜单。地图场景中的 Esc 暂时调用该方法；暂停菜单实现后由暂停菜单接管，规则见 [战斗操作与快捷交互](../战斗与操作/战斗操作与快捷交互.md)。

## 角色档案

角色档案是一个字典，描述装载一个角色所需的全部数据：标识、显示名、插画标识、显示比例、碰撞半径、移动速度与动作配置。地图和角色节点只读取这份数据，不关心它来自哪里。

第一阶段由 `Scripts/Character/character_library.gd` 的 `CATALOG` 提供预设角色，未登记的标识回退到洛恩，这与主菜单插画目录 `menu_portrait.gd` 的处理方式一致。角色创建流程实现后在 `start_new_game` 之前产出同样结构的档案；存档服务实现后由存档提供，`GameFlow` 与下游无需改动。

档案字段与 [角色存档与长期成长](../角色系统/角色存档与长期成长.md) 的一档一角色结构对应，职业、装备与外观配置按该文档在后续阶段加入。

## 扩展点

- 角色创建：在主菜单与 `start_new_game` 之间插入创建界面，产出角色档案。
- 存档读取：「继续旅程」读取最近存档得到角色档案，直接调用 `start_new_game` 的同一路径。
- 地图切换：`GameFlow` 目前固定进入城市庭院，接入地下城与安全楼层时按目标区域选择地图场景，区域职责见 [城市与地下城探索](../世界与探索/城市与地下城探索.md)。
- 联机：Listen Server 下由主机决定世界装载，客户端沿用同一角色档案结构，见 [玩家主机联机](../联机/玩家主机联机.md)。

## 验证

`Tests/test_game_flow.gd` 覆盖单例装载、角色档案内容、切换到城市庭院、返回主菜单和未知角色标识回退。执行 `godot --headless --path . --script Tests/test_game_flow.gd`。
