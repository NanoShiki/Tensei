# 项目阶段与当前进度

本文统一记录项目阶段、当前阶段、阶段目标及完成情况。各模块的具体规则由对应文档维护。

## 当前阶段

当前阶段：**第一阶段——卡牌战斗原型**。

当前状态：实现中。主菜单可进入一场横版卡牌战斗原型，时间轴、出卡、资源消耗与胜负结算已通过无头测试。

## 方向调整记录

项目已从俯视角即时动作调整为横版卡牌战斗。卡牌是能力的表示形式，不采用抽牌、过牌与弃牌堆；局内按楼层持续深入，体力、MP 与生命跨战斗结算且不自动补满。完整方向见 [整体玩法设计](整体玩法设计.md)。

调整带来的作废内容：俯视四向行走与跑步素材、俯视角色动作资产规范、以及基于 WASD 的移动实现均已删除，相关实现的 PR 未合并。人物设计稿、表情设定与原画继续沿用。

## 第一阶段目标与完成记录

目标流程：启动游戏 → 主菜单 → 进入一场横版卡牌战斗 → 按时间轴出卡战斗 → 分出胜负并结算。

- [x] 游戏可启动至主菜单，展示洛恩初始原画与左侧菜单。
- [x] 主菜单可进入战斗场景，带入洛恩的角色数据与卡组。验证：`Tests/test_main_menu.gd` 保持通过；角色弹层提供「进入战斗」入口，由 `GameFlow.start_battle` 装载洛恩并切换到 `Scenes/Battle/battle.tscn`。
- [x] 横版战斗画面可用：我方与敌方按站位呈现，具备行动时间轴、卡牌区与资源区。验证：`Tests/test_battle_screen.gd` 检查分区构建；`Tests/capture_battle.gd` 截取 1280×720 画面核对角卡完整可见与资源条颜色。限制：使用占位色块，尚无角色动作与卡面。
- [x] 卡牌可以打出，正确结算体力、MP 与生命，资源耗尽时保底行动仍可用。验证：`Tests/test_battle_logic.gd` 覆盖消耗、补给次数、零体力保底与非法目标无副作用。
- [x] 时间轴按行动耗时与速度推进，敌人的蓄力攻击可提前预览。验证：逻辑测试覆盖顺序、预览不改真实状态、石拳巨像蓄力两步与打断。
- [x] 战斗可分出胜负并给出结算，流程可从主菜单开始连续完成，经过实际运行验证。验证：逻辑测试覆盖胜负判定；界面测试循环出卡至结果面板出现。尚未做人工整局手感验收。

第一阶段的验证目标是回答一个问题：没有抽牌随机性的卡牌战斗是否成立。范围限定为 1 名角色对 2 名敌人，其中一名具备可预览的蓄力攻击，不实现队伍编成与楼层推进。具体规则见 [卡牌战斗](../战斗系统/卡牌战斗.md)，资源规则见 [资源与体力](../战斗系统/资源与体力.md)。

实现规格与代码均已落地，见 [战斗原型实现](../战斗系统/战斗原型实现.md)。玩法结论（没有抽牌的卡牌战斗是否成立）仍待人工游玩后确认。

第一阶段允许随讨论补充功能、验收条件和验证方式。新增要求直接更新本节，并同步涉及的模块文档。完成记录应填写实际验证结果；勾选条目时说明验证方式及仍存在的限制。
