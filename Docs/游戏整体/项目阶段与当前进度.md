## 第一阶段目标与完成记录

目标流程：启动游戏 → 主菜单 → 创建角色 → 进入可操作场景 → WASD 控制角色移动并执行攻击。

- [ ] 主菜单可进入角色创建流程。
- [ ] 能完成角色创建，并将所创建的角色带入可操作场景。
- [ ] 玩家可使用 WASD 控制该角色移动。
- [ ] 玩家可操作该角色执行攻击，并看到对应反馈。
- [ ] 上述流程可以从主菜单开始连续完成，经过实际运行验证。

角色创建遵循 [角色创建与外观动画](../角色系统/角色创建与外观动画.md)，角色归属遵循 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)；第一阶段的预设、随机、自定义选项数量及保存读档覆盖范围待细化。移动和攻击遵循 [战斗操作与快捷交互](../战斗与操作/战斗操作与快捷交互.md)，具体武器、攻击方式、目标与判定验证范围待补充。

第一阶段允许随讨论补充功能、验收条件和验证方式。新增要求直接更新本节，并同步涉及的模块文档。完成记录应填写实际验证结果；勾选条目时说明验证方式及仍存在的限制。
