## 第一阶段目标与完成记录

目标流程：启动游戏 → 主菜单 → 创建角色 → 进入可操作场景 → WASD 控制洛恩移动，正常播放待机、行走和跑步动画。

- [x] 游戏可启动至主菜单，展示洛恩初始原画与左侧菜单。
- [ ] 主菜单可进入完整角色创建流程；当前仅提供洛恩入口展示。
- [ ] 能完成角色创建，并将所创建的角色带入可操作场景。
- [ ] 玩家可使用 WASD 控制该角色移动。
- [ ] 待机、行走与跑步动画按方向与移动状态正确切换，无明显切片、漂移或循环问题。
- [ ] 上述流程可以从主菜单开始连续完成，经过实际运行验证。

角色创建遵循 [角色创建与外观动画](../角色系统/角色创建与外观动画.md)，角色归属遵循 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)；第一阶段的预设、随机、自定义选项数量及保存读档覆盖范围待细化。移动操作参考 [战斗操作与快捷交互](../战斗与操作/战斗操作与快捷交互.md)，第一阶段暂不考虑武器和攻击，最高目标为剑士移动与动画正常播放。

第一阶段允许随讨论补充功能、验收条件和验证方式。新增要求直接更新本节，并同步涉及的模块文档。完成记录应填写实际验证结果；勾选条目时说明验证方式及仍存在的限制。
