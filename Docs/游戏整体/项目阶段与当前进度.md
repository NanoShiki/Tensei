# 项目阶段与当前进度

当前阶段：**2D 简化回合制战斗与逐层地图原型**。

## 已确定目标

每层一张类似《杀戮尖塔》的分支节点地图，整体预计几十层。横版战斗左侧己方、右侧敌人，技能和道具通过底部分区图标选择，再点目标使用。每回合每人默认行动一次，特殊技能或效果可增加次数。

DND、博德之门提供回合制参考。规则按 2D 简化，不引入 3D 环境交互；药水按具体定义直接对自己或敌人作用。长期培养、城市准备、Steam 与联机等项目目标继续由对应模块维护。

## 已实现

- 主菜单的独立战斗演示与逐层探索双入口。
- 洛恩对哥布林的横版战斗、单次行动、结束回合、先攻、命中、闪避与回气。
- 治疗药水选自己、灼烧药水选敌人，效果、库存与行动统一结算。
- 底部装备、技能、道具和结束回合分区；鼠标点选、1–6 快捷键、右键/Esc 取消与空格结束回合。
- 透明洛恩与哥布林角色素材；静态战斗姿态和结果浮字。
- 配置化 30 层演示：每层独立节点图、战斗、营地、补给、出口，生命和药水延续与节点防重复结算。

30 层共用拓扑模板，部分节点类型随种子变化；尚无几十层独立内容。地图与角色状态只在内存中，当前不提供保存、读档或正式返程收益。

## 验证与待验收

本次 Godot 4.7.2 战斗逻辑、战斗界面与主菜单测试全部通过；1280×720 和 960×540 画面已检查。逻辑与界面测试入口见 [战斗原型实现](../战斗系统/战斗原型实现.md)。最终验证记录在该文档维护。新角色素材已生成，用户美术认可与整局手感验收待完成。

## 后续阶段

先验证一次行动的选择是否足够清楚、有趣；下一步建议用两至三层验证返程、节点怪物刷新进度、交战或避战、回城结算，再接入材料与锻造闭环。完整提案见 [整体玩法设计](整体玩法设计.md)。随后讨论多队员、更多敌人与技能、正式层数和地图主题。队伍编成、长期成长、城市补给、怪物之宴、返程、联机、存档和终局尚待实现。原型实现与正式设计状态应分别维护。
