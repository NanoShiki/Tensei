# 战斗原型实现

状态：2D 简化回合战斗与逐层地图 Demo 已实现。主菜单 → 开始旅程 → 逐层探索或战斗演示。

## 实现组成

| 路径 | 职责 |
| --- | --- |
| `Scripts/Character/character_library.gd` | 洛恩初始 HP、AC、命中、敏捷、药水库存 |
| `Scripts/Battle/ability_library.gd` | 稳定能力 ID，目标、效果、骰点或药水库存字段 |
| `Scripts/Battle/battle_state.gd` | 先攻、统一行动次数、目标校验、骰点、结算 |

| `Assets/Battle/` | 透明角色图与技能图标 |

## 战斗接口与顺序

`setup(character, floor_number, seed_value)` 拷贝角色数据；随机数种子可用于测试复现，正常游玩随机初始化。开战决定固定先攻顺序。

`reason(id)` 查询不可用原因；`use_ability(id, target)` 先验证回合、能力、行动、库存与目标，全部合法后扣一次行动并执行效果。攻击命中失败也消耗行动；非法选择不消耗行动、物品或随机数。`grant_actions(amount)` 为特殊效果增加当前行动次数，不跨回合积攒。

药水通过 `target`、`effect`、`amount`、`stock` 配置直接影响单位。治疗与伤害共享结算入口，无环境中间实体。`end_turn()` 主动结束己方回合；`enemy_turn()` 执行敌人一次攻击并推进。`outcome` 为 ongoing、victory 或 defeat。

界面在异步敌人提示和结果浮字期间锁定操作，结算只回写一次。战斗结束前地图不能进入其他节点，胜利返回地图后才解锁下一步。

## 地图与会话

地图参数为探索种子、楼层序号和总层数；默认 30 层，每层使用同一拓扑模板并变化部分节点。局部节点 ID 用于当前地图连线，完整 key 组合远征 ID、层号和局部节点 ID。每次 setup 创建新远征身份；同种子仍可生成同一地图。历史楼层与实际通过路线驻留内存，floor_snapshot 返回隔离副本。字段含义见 [远征状态与路线保留](../世界与探索/地下城推进与怪物之宴.md)。

`enter(id)` 校验连线与完成状态；战斗节点记入 pending，胜利后才设为当前位置。`finish_battle(hero, victory)` 保存生命与两类药水，防重复结算。出口保留原层并生成下一层或完成探索；重复 generate_floor 不会清空已生成的当前层。失败标记为本趟终止，重新 setup 后才能开始新旅程。`begin_return()` 切换返程，`return_targets()` 预览全部合法上行节点，`step_return(expected_key)` 校验目标后逐步返回，`return_summary()` 返回回城摘要副本。下潜与返程轨迹分别记录，移动先推进全远征刷新步数，再检查目的地遭遇。数据只驻内存，无正式存档、网络、掉落背包或 Steam 接入。

## 验证

- `Tests/test_battle_logic.gd`：每回合一次行动，药水与攻击共用次数，额外行动，非法目标无副作用，闪避时效，药水库存，先攻回合，暴击/未命中，胜负和 30 层可达性、资源延续、重复奖励防护。
- `Tests/test_floor_run.gd`：跨层历史、真实分支路线、节点标识、快照隔离、待结算锁定、失败终止、重新出发与重复奖励防护；三层返程、跨层原地图、最深出口返回、旧目标重复回调和单次回城摘要。
- `Tests/test_battle_screen.gd`：技能选择与取消、目标限制、实际点击、结束回合、药水和胜利面板、地图进出、实际按钮返程及回城摘要、小窗口缩放。
- `Tests/test_main_menu.gd`：主菜单原有交互回归。
- `Tests/capture_battle.gd`：渲染检查，可用 `TENSEI_CAPTURE_PATH` 指定截图；后续参数见脚本。

运行方式：`godot --headless --path . --script Tests/test_battle_logic.gd`；界面测试同理替换脚本路径。截图使用非 headless 渲染；`TENSEI_CAPTURE_MODE=target` 选择灼烧药水目标，`map` 截图下潜地图，`return` 截图返程，`returned` 截图回城摘要，`TENSEI_CAPTURE_SMALL=1` 使用 960×540 窗口。

## 当前限制

仅有洛恩与哥布林，角色采用单帧站姿配合浮字，没有骨骼动画、独立武器挂接或完整攻击动作。装备只读。数值未平衡。多队员、反应/豁免等扩展、持久化、联机和正式地牢内容待后续评估。
