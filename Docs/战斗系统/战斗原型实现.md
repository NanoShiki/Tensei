## 独立战斗演练配置

主菜单“开始旅程”→“战斗演练配置”，滚动选择四职业、等级 1–5、三种武器、布衣／铁甲、普通／重甲／迅足哥布林、双敌巡逻队或队长、己方 1–3 人、敌人楼层参数 1–30，以及整数种子 0–2147483647。每次从满血和初始药水开始；等级保留真实技能门槛，队友采用同演练等级、各自基础属性和木剑。演练不要求实际成员资格和已获得装备。

演练沿用实际战斗、点技能后点目标、独立成员行动与 GM。战斗中“演练配置”可重新选择，动作反馈／暂停／其他窗口／GM 展开时不能打开；取消保留当前战斗，开始替换当前演练。胜利后“再试一次”保持配置和种子、恢复初始状态；同配置和相同行动能重现先攻与骰子。演练不创建角色档案，不写个人存档、远征奖励或共享成长；回菜单后继续原角色恢复手动保存时点。读档或新建正式角色清除演练配置，城市与探索拒绝演练接口中断。

配置 `training_library.gd` 负责可信 ID／范围校验与独立角色参数；`training_panel.gd` 提供点击选择；诊断记录 `training.configured/started/finished/rejected`，含配置、实际战斗／随机状态和共享快照。内容版本仍为 `demo-armor-1`，配置不持久化。

## GM 测试菜单

当前 Demo 由 `GameFlow` 创建一个常驻的 `Scripts/Debug/gm_panel.gd`（CanvasLayer）。右上角 GM 悬浮按钮展开菜单，关闭按钮或 Esc 收起。指令位于 ScrollContainer，条目较多时可滚轮上下滑动。当前提供“秒杀当前敌人”“恢复存活成员”“补足测试药水”和“打开日志目录”；上下滚动查看全部指令。

秒杀清除当前全部敌人，不消耗行动、药水或随机数，通过战斗状态判定胜利，再调用现有场景结算及刷新流程。探索节点会正常完成，重复点击不重复回写。主菜单、地图、已结束战斗及动作反馈播放期间禁用，并显示原因；动作结束后自动恢复。菜单展开时屏蔽战斗快捷键，菜单不暂停游戏。

恢复命令将存活己方生命补满，倒下成员保持零生命；补给将治疗与灼烧药水各补至至少 10，已有更多库存保留，不扣金币。城市／深入／返回地图和进行中的战斗可执行，主菜单、窗口打开、动作中和已结束战斗拒绝。地图恢复编队时重新核对共享档案，档案不可用不部分治疗。两项不推进移动时钟、行动、先攻、随机数、任务和共享经验；测试修改随正常战斗回写，并会进入手动存档。界面明确提示测试改动，GM 前后状态另写诊断日志。

扩展入口：`register_command(id, title, description, execute, reason)`。每条指令使用唯一 ID、中文标题／说明、返回成功与否的执行 Callable，以及返回不可用原因字符串的 Callable（空串表示可用）。面板只负责登记、可用性、滚动与执行反馈；具体模块实现操作与校验，执行前再次检查。失效回调会禁用。当前战斗上下文通过 `gm_battle_context` 分组查找，场景切换后不会沿用已释放节点。

当前 GM 入口在 Demo 中默认启用，供开发验收；当前没有命令行、正式权限体系或联网 GM 指令。后续正式发行时按发行方案决定是否保留入口。

## 战斗接口与顺序

`setup(character, floor_number, seed_value, captain, companion, enemy_kind, second_companion, second_enemy_kind)` 拷贝角色数据；末项空串表示单敌，独立敌方实例 `goblin_b` 保留稳定内容 ID；随机数种子可用于测试复现，正常游玩随机初始化。开战决定固定先攻顺序。

`reason(id)` 查询不可用原因；`use_ability(id, target)` 先验证回合、能力、行动、库存与目标，全部合法后扣一次行动并执行效果。攻击命中失败也消耗行动；非法选择不消耗行动、物品或随机数。`grant_actions(amount)` 为特殊效果增加当前行动次数，不跨回合积攒。

药水通过 `target`、`effect`、`amount`、`stock` 配置直接影响单位。治疗与伤害共享结算入口，无环境中间实体。`end_turn()` 主动结束己方回合；`enemy_turn()` 执行敌人一次攻击并推进。`outcome` 为 ongoing、victory 或 defeat。

界面在异步敌人提示和结果浮字期间锁定操作，结算只回写一次。战斗结束前地图不能进入其他节点，胜利返回地图后才解锁下一步。

## 地图与会话

地图参数为探索种子、楼层序号和总层数；默认 30 层，每层使用同一拓扑模板并变化部分节点。局部节点 ID 用于当前地图连线，完整 key 组合远征 ID、层号和局部节点 ID。每次 setup 创建新远征身份；同种子仍可生成同一地图。历史楼层与实际通过路线驻留内存，floor_snapshot 返回隔离副本。字段含义见 [远征状态与路线保留](../世界与探索/地下城推进与怪物之宴.md)。

`enter(id)` 校验连线与当前移动状态；战斗节点记入 pending，胜利后才设为当前位置。`finish_battle(hero, victory)` 保存生命与两类药水，防重复结算。出口保留原层并生成下一层或完成探索；重复 generate_floor 不会清空已生成的当前层。失败标记为本趟终止，重新 setup 后才能开始新旅程。`begin_return()`／`begin_descent()` 切换返回或深入方向，`return_targets()` 预览全部合法上行节点，`step_return(expected_key)` 校验目标后逐步返回，`return_summary()` 返回回城摘要副本。`descend_floor(expected_floor)` 处理在旧层出口掉头向下，重新激活历史层节点而不重新生成。下潜与返程轨迹分别记录，移动先推进全远征刷新步数，再检查目的地遭遇。地图与城市可手动保存与继续，金币／铁片／铁剑已接入；完整背包、网络及 Steam 接入待实现。存档服务与异常边界见 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)。
