# 行动与补给

状态：默认每回合每人行动一次为用户已确定规则；当前 Demo 已实现行动次数、生命与两类药水。

## 行动次数

每个角色在自身回合开始获得 1 次行动。攻击、技能、防御与道具共用同一额度。用尽后各按钮保留并置灰，提示行动次数已用尽；玩家点击结束回合推进。尚未行动也可以直接结束。

特殊技能或效果可以增加本回合行动次数。未使用的次数不带入下回合。资源逻辑仅用一个剩余行动计数，无动作类别划分。

## 持续资源

| 资源 | 当前规则 |
| --- | --- |
| 生命 | 战斗、节点与楼层间延续；不自动补满 |
| 治疗药水 | 直接对自己恢复 12 HP，每次消耗一次行动与一瓶 |
| 灼烧药水 | 直接对敌人造成 8 伤害，每次消耗一次行动与一瓶 |
| 回气次数 | 每场战斗一次，恢复 8 HP，消耗一次行动 |

两类药水共享配置结构中的目标、效果类型、效果量与库存字段，按各自定义执行。药水用途后续可以扩展；当前不计算投掷、抛物线、碰撞、地形或环境交互。

满血时不能使用恢复能力，目标错误、数量不足、行动耗尽或非己方回合均不扣资源。攻击未命中仍消耗行动。

## 探索补给

营地节点恢复 10 HP，上限为最大生命；补给节点给予一瓶治疗药水。每处营地／补给只发放一次资源；节点可以反复经过，已使用时在地图明确标记。向上退到未使用营地可休整后继续深入；切换方向不计步，切层保留资源与领取状态。入口新开探索时初始化角色，单场演示的「再试一次」明确创建全新战斗。

地图与城市可按 B 打开背包，非战斗安全状态下消耗一瓶治疗药水恢复至多 12 生命，不推进移动或怪物刷新计时。满血、无药和非安全状态禁止用药。战斗内使用仍消耗一次行动。城市采购、手动保存和多记录读取已接入，用药后仍需手动保存；背包格位与正式休整成本待设计，见 [角色存档与长期成长](../角色系统/角色存档与长期成长.md)。

体力、MP、疲劳与装备耐久不参与当前战斗计算。以后若增加长期资源，需要独立评估复杂度，不能默认为已经确定的规则。
