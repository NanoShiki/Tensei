# 地图实现与城市庭院

状态：第一阶段已实现首张可行走地图「城市庭院」。区域连接、出入口与地下城地图待实现，区域设计见 [城市与地下城探索](城市与地下城探索.md)。

## 地图的组成方式

地图由三层独立数据组成：手绘地面图负责视觉，碰撞体负责可行走边界，标记点负责出生与连接。三层分开的原因是视觉与逻辑可以各自演进，地下城改用程序生成时只替换地面与碰撞的产出方式，角色和流程代码不变。

项目采用手绘整图而非瓦片拼接，与 [美术风格与素材制作](../美术/美术风格与素材制作.md) 的非像素手绘方向一致；瓦片拼接会让手绘风格出现重复感。代价是单张地图的尺寸受图片分辨率限制，大型地下城需要分区出图或分块拼接，具体方案在地下城实现时确定。

## 场景结构

地图场景统一采用下列结构，由 `Scripts/World/world_map.gd` 装载。城市、安全楼层与地下城复用同一脚本，差异体现在场景资源本身。

```text
CityCourtyard (Node2D)
├─ Ground (Sprite2D)          手绘地面图，左上角对齐世界原点
├─ Entities (Node2D)          玩家与后续 NPC、怪物，按 Y 排序
├─ Obstacles (StaticBody2D)   围墙与物件的碰撞形状
└─ Markers (Node2D)
   └─ PlayerSpawn (Marker2D)  出生点，后续增加出入口标记
```

地图的世界矩形由地面图尺寸与缩放算出，同时作为相机边界。相机是玩家的子节点，跟随玩家并限制在地图矩形内。

角色档案由 `GameFlow` 提供；单独运行地图场景时回退到预设角色，便于按 F6 直接检查地图，见 [场景流程与角色装载](../游戏整体/场景流程与角色装载.md)。

## 城市庭院规格

| 项目 | 当前值 |
| --- | --- |
| 地面图 | `Assets/Maps/CityCourtyard/城市庭院地图.png`，1024×1024 |
| 缩放与世界尺寸 | 2 倍，世界矩形 2048×2048 |
| 可行走区域 | 世界坐标 x 430 至 1690、y 660 至 1540 |
| 出生点 | (1060, 1430)，庭院门内侧 |
| 障碍 | 四面围墙各一个矩形，水井与练功木桩各一个圆形 |

画面内容为城镇边缘的家园庭院：石板与泥土地面、四周围墙与屋顶、下方木门、水井、木箱、练功木桩与树木。投影与角色动作图一致，为 45 度三分之四俯视。素材由生图模型生成，按 [美术风格与素材制作](../美术/美术风格与素材制作.md) 的流程检查线条、色块、光源与细节密度后采用。

## 已知限制

- 障碍物属于地面图的一部分，角色走到树木和屋顶后方不会被遮挡。需要遮挡时把对应物件拆成独立贴图并放入 `Entities` 参与 Y 排序。
- 可行走边界目前用矩形和圆形近似，围墙的斜向透视边缘存在少量误差。边界精度要求提高时改用 `CollisionPolygon2D` 描边。
- 地面图放大 2 倍显示，画面在近距离观察时略有柔化。提高清晰度需要分区出图或更高分辨率素材。
