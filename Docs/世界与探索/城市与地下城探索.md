# 城市与地下城探索

状态：已实现城市整备最小闭环、自由选路返程、按步数刷怪及回城摘要。城市目前采用操作面板；完整设施、眷族服务和避战待实现。

## 当前城市 Demo

新角色先进入城市整备，从第一层出发；探索胜利积累金币、铁片与现有补给，沿上行路线回城后通过摘要页“进入城市整备”，再购买药水、打造铁剑和重新出发。角色身份、随身物资与装备跨远征保留；每次出发创建新远征 ID 和地图，清空该趟路线与移动步数。

| 服务或来源 | 当前 Demo 数值与行为 |
| --- | --- |
| 战斗胜利 | 3 金币、1 铁片，结算一次即加入持有资源；刷新后重新击败可再次获得 |
| 旅店休整 | 免费恢复全部生命；满血时禁用，免费规则为 Demo 临时参数 |
| 药水商店 | 3 金币购买 1 瓶治疗药水；不足时禁用 |
| 城市工坊 | 6 金币、3 铁片打造并自动装备铁剑；剑击和强攻伤害 +2，命中率不变；已持有时禁用 |

购买和打造先校验条件，再一次性扣除资源并发放产出；失败不扣款。金币、铁片、药水和武器都在角色快照内，回城与进入城市不再次发放战利品。当前无外部公共仓库／经济账本，读取旧记录会同时恢复旧余额及旧世界状态，各条记录互不累加。死亡仍结束本次会话，可读取已有记录，正式损失规则待设计。

城市和地图沿用同一个“保存并退出”窗口，城市记录读取后直接回到整备；交易和回城仍不自动保存。旧地图存档补零金币、零铁片和木剑，原文件保留。存档交互范围保持用户已验收版本。

验收：F5 → 开始旅程 → 命名角色 → 进入城市 → 从第一层出发。用 GM 赢至少 3 场，观察每次金币 +3、铁片 +1；沿上行路线回到城市，购买 1 瓶治疗药水，再打造铁剑，金币与材料按标价扣除。保存并继续应回到城市且装备仍为铁剑；再次出发角色与持有资源保持一致，战斗装备栏显示铁剑，剑技悬停显示额外 2 点伤害。满血休整、余额不足交易和重复打造应禁用。

`Tests/test_city_loop.gd` 覆盖完整两趟循环、重复领奖防护、交易条件、实际城市按钮、城市保存读取、旧记录兼容和同随机数下铁剑伤害差异。完整背包格位、武器切换、任务、职业、眷族与正式城市美术尚未接入。

城市顶部显示阶段目标“打造铁剑，挑战第 3 层守关队长并回城”；打造为准备建议，进入挑战不检查装备。击败后回城显示已完成，可继续探索与再次出发。规则见 [回合制战斗](../战斗系统/回合制战斗.md)。

## 已确定方向

城市或家园与地下城构成相连的冒险空间。玩家可以在探索途中返回，身上的物品延续持有。空间连接允许存在场景加载；玩法应保证角色、物品与进度的连续性。

地下城参考《地错》的安全楼层思路，设置阶段性的休整、任务交接与交易区域。地下城补给和交易受到资源、地点与价格限制，具体规则见 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)。

城市中的主要生产、交易和委托服务由不同眷族经营。玩家选择到哪家工坊打造、在哪家店铺采购，建议也能推动对应眷族的长期成长；当前加入的眷族决定成员任务与专业加成。服务与归属规则见 [眷族体系与成长](../角色系统/眷族体系与成长.md)。

## 区域职责建议

地下城难度随深度逐步提高，玩家通过获得武器、转职与技能培养角色，再挑战更深层。浅层持续提供可用资源，支持稳妥积累和重复探索。具体资源分布、收益差异、楼层资格和敌人缩放规则待设计。

成长后的角色可单人继续常规探索，也可联机护送新手。另有主游戏养成完成后才制作的独立终局肉鸽挑战；专门地图、首领强度与随机效果见 [深层终局挑战](深层终局挑战.md)。

| 区域 | 主要用途 | 玩家决策 |
| --- | --- | --- |
| 城市或家园 | 从不同眷族接委托、打造、交易、补给、存放物品与成长准备 | 去哪家服务、为哪家积累贡献、为下一段探索投入什么 |
| 地下城探索区域 | 战斗、收集、宝箱、眷族任务与事件 | 当前收益是否值得继续深入 |
| 安全楼层 | 有限休整、交接和高成本补给 | 支付便利成本或带着所得返回 |
| 首领或特殊区域 | 提供特殊敌人、素材与条件事件 | 队伍是否具备挑战准备 |

地下城内的楼层推进方式、路线选择与怪物之宴见 [地下城推进与怪物之宴](地下城推进与怪物之宴.md)；局内资源不自动补满，休整与补给规则见 [行动与补给](../战斗系统/行动与补给.md)。

## 返回与持续状态

当前原型通过地图的“向上返回”沿玩家选择的向上路线移动；途中可随时“继续深入”，回到第一层入口并点击“回到城市”才显示“平安归来”摘要。返程不重复领取营地和补给，刷新后胜利正常获得战利品。摘要只生成一次，城市整备继续保留资源。地图操作见 [地下城推进与怪物之宴](地下城推进与怪物之宴.md)。以下为后续完整设计。

主动返回是正常的探索选择，方向可以在途中反复切换；退回营地后可以接着深入，同一趟历史楼层与资源保持连续。每次远征从第一层出发，返程可选择任意合法的向上分支，包括未到访节点。每移动一步，已清理节点的怪物刷新倒计时减少 1；停留和战斗不额外扣步。已实现重新遇敌，避战与强度平衡待迭代。战利品持有规则见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

常规远征地图切换时，分别处理角色物品、眷族任务进度、队友成长和职业解锁。终局挑战的临时赐福只在独立模式中生效，见 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)。

## 表现与信息

入口、出口、安全楼层和可交互设施应在场景中具备明确标识。地图应帮助玩家理解当前位置、已发现的返回路径和任务目的地；地图信息的揭示范围待细化。
