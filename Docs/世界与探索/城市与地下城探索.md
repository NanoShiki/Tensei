# 城市与地下城探索

状态：策划初稿，待实现。

## 已确定方向

城市或家园与地下城构成相连的冒险空间。玩家可以在探索途中返回，身上的物品延续持有。空间连接允许存在场景加载；玩法应保证角色、物品与进度的连续性。

地下城参考《地错》的安全楼层思路，设置阶段性的休整、任务交接与交易区域。地下城补给和交易受到资源、地点与价格限制，具体规则见 [任务交接与补给交易](../任务与交易/任务交接与补给交易.md)。

## 区域职责建议

| 区域 | 主要用途 | 玩家决策 |
| --- | --- | --- |
| 城市或家园 | 接取委托、存放物品、打造、补给与成长准备 | 为下一段探索投入哪些资源 |
| 地下城探索区域 | 战斗、收集、宝箱、事件和肉鸽机会 | 当前收益是否值得继续深入 |
| 安全楼层 | 有限休整、交接和高成本补给 | 支付便利成本或带着所得返回 |
| 首领或特殊区域 | 提供特殊敌人、素材与条件事件 | 队伍是否具备挑战准备 |

## 返回与持续状态

主动返回是正常的探索选择。返回方式、耗时与危险程度待确认，当前不承诺随时传送。战利品持有规则见 [背包与物品流转](../装备与物品/背包与物品流转.md)。

地图切换时，需要分别处理角色物品、任务进度、职业解锁和肉鸽效果。各自按对应规则延续，肉鸽效果有效期见 [全局肉鸽机制](../肉鸽系统/全局肉鸽机制.md)。

## 表现与信息

入口、出口、安全楼层和可交互设施应在场景中具备明确标识。地图应帮助玩家理解当前位置、已发现的返回路径和任务目的地；地图信息的揭示范围待细化。

## 待确认

- 楼层生成方式、楼层连接和安全楼层分布。
- 返回是否需要原路撤退、解锁捷径或消耗道具。
- 安全区域的保护范围及特殊事件能否破坏安全。
- 队友能否分处城市与地下城，跨区域时的组队规则。
- 怪物、宝箱、商店和事件的刷新条件，以及防止反复进出重复获奖的规则。
