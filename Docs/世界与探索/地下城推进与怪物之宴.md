# 地下城推进与怪物之宴

状态：策划初稿，待实现。连续推进、路线选择与怪物之宴为已确定方向；层数结构、收益曲线与触发条件属于建议，需要原型验证。当前阶段只实现持续深入，返程与避战在后续阶段设计。

## 推进结构

进入地下城后按楼层连续推进。每完成一层，玩家在下一层的若干路线中选择其一，路线类型在进入前可见，具体内容进入后才揭示。

| 路线类型 | 内容 | 决策 |
| --- | --- | --- |
| 战斗 | 常规敌人组合 | 花多少资源换取掉落 |
| 精英战斗 | 机制更强的敌人 | 风险与稀有掉落的取舍 |
| 事件 | 神明赐福、遭遇、抉择 | 接受代价换取强化 |
| 商人 | 高价补给与卡牌交易 | 是否为补给让出背包格位 |
| 安全楼层 | 有限休整与任务交接 | 支付便利成本或继续深入 |
| 怪物之宴 | 高风险高回报的连续战斗 | 储备是否足以承受 |

资源只减不增，收益随深度上升。玩家每层都在回答“再打一层吗”。这一取舍是地下城玩法的核心张力，资源规则见 [资源与体力](../战斗系统/资源与体力.md)。

## 收益与压力曲线

建议收益随层数明显上升，资源压力同步上升，两条曲线共同构成赌博感：

- 掉落的数量与稀有度随层数提升，深层素材是打造高级武器的必要来源，见 [武器掉落与打造](../装备与物品/武器掉落与打造.md)。
- 敌人的机制复杂度随层数提升，不只是数值变大。
- 补给价格随深度上升，安全楼层的休整成本同步上升。
- 背包格位固定，深入越久，补给与战利品的空间冲突越明显。

具体层数、分段与数值曲线待设计。

## 怪物之宴

怪物之宴是地下城的高风险事件，参考《地错》中地下城异常涌出的设定。

- **形式**：大量敌人分波涌出，波次之间不提供休整，全部击退才算完成。
- **作用**：它是对资源储备的检验，也是素材与补给的主要来源，为打造和补给循环提供产出。
- **触发**：出现预兆后由玩家选择是否进入，从而成为一次明确的赌博决策。是否存在强制触发的深层版本待确认。
- **收益**：大量素材、稀有卡牌与补给，具体产出规则待设计。

怪物之宴的强度应当按“携带充分的队伍可以完成，勉强推进的队伍会被拖垮”来设计，使前期的补给准备产生回报。

## 返程与避战

当前阶段只实现持续深入，结构上预留以下接口：

- 每层结束时的选择列表可以加入返程与撤退选项。
- 路线类型可以加入可规避的战斗节点。
- 安全楼层作为返程与再出发的中转点。

返程方式、耗时、危险程度与是否需要消耗道具待确认，相关方向见 [城市与地下城探索](城市与地下城探索.md)。
