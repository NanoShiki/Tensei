# 深层终局挑战

状态：设计草案，待实现。终局为主游戏养成后的独立肉鸽挑战；专门地图、较长流程、此前各层首领提高强度并带随机效果是设计方向，具体入口、参数与流程待确认。优先完成常规冒险。

## 定位与进入

角色通过常规地下城、锻造、转职和眷族任务持续成长后，可带着长期角色、个人装备和所属眷族的已培养队友进入终局；其他玩家可携自己的长期角色合作挑战。终局为成熟角色提供高强度、可重复的战斗目标，不重置主游戏培养成果。终局入口与解锁条件待定。

可制作最深层主题的专门挑战地图，单局流程较长；这张地图属于终局模式，不强制沿常规远征的第一层至最深层路线行进。具体时长、资格、撤退、继续挑战和保存规则待确认。普通地下城仍保留自己的深层探索与主线目标。

## 首领与随机化

- 将此前不同楼层的首领纳入终局候选池，提升到相同的终局数值或强度档位，使早期首领也能对成熟角色形成挑战。
- 首领随机出现，并可随机附加效果，形成多次挑战之间的差异。出现数量、顺序、重复限制以及同时或依次登场的方式待设计。
- 终局结合肉鸽机制增加变化。玩家赐福、环境效果和首领强化分别记录对象、来源与有效期，由 [终局肉鸽机制](../肉鸽系统/终局肉鸽机制.md)协调。

“相同数值”目前记录为统一的终局强度目标。生命与攻击等字段是否采用完全相同数值，或依首领攻速、体型和机制换算到同档威胁，待平衡验证。具体缩放公式、难度档位与是否支持继续抬高上限尚未确定。

建议在统一基础档位上叠加首领特性、人数适配及合法词条组合，保留每个首领可辨识的机制。组合需有互斥、叠加上限和可应对性检查，避免随机产生无法应对的招式。护盾、元素变化或场地限制可作为词条研究示例，尚未定案。

## 地图、反馈与奖励建议

专门地图可研究多段遭遇、连接路线和休整点，支持较长流程中的战斗与补给节奏。地图布局是否固定、局部随机或整体生成待确认。

进入前展示难度与资格，遭遇时清楚呈现首领强化和随机效果，保持手绘画面的攻击预警可读性。奖励可研究外观、称号、挑战记录与不阻断主游戏成长的装备素材；具体产出、分配、领取时机、重复挑战收益及撤退损失待设计。终局奖励不能成为完成常规养成的必需门槛。

## 实现边界建议

将地图、首领定义、终局缩放配置、遭遇池与效果池分别配置，通过稳定标识关联，复用普通楼层首领并应用终局参数。新增首领或词条通过内容注册与兼容检查接入，为创意工坊预留扩展入口，开放范围见 [发行与创意工坊](../平台与扩展/发行与创意工坊.md)。

联机由主机生成或确认随机结果并同步；保存时记录已生成遭遇、效果和奖励状态。建议使用可复现随机种子辅助调试，同时保存已确定结果，避免重连或读档重复生成和领取。

## 待验证场景

- 强角色单人及组队均可进入相应终局挑战，人数缩放规则另行验证。
- 早期和深层首领提升至统一档位后，仍保留机制差异与可应对空间。
- 重复挑战可产生不同首领与词条组合，同次联机中的所有玩家看到一致结果。
- 较长单层流程的撤退、断线、保存及奖励恢复符合最终确定的规则。
